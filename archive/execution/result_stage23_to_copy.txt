الإصلاحات المطبقة (4 إصلاحات)
═══════════════════════════════════════════════════════════

1️⃣ استدعاء دالة كجملة قائمة بذاتها:
   الصيغة فتح("...") كانت جُملة استدعاء بدون ⎕ أو أسناد،
   والمحلل لم يكن يدعمها.
   الحل: أُضيف "استدعاء_جملة" إلى حلل_بيان (نتيجتها تُنفَّذ وتُتجاهل)
   وإلى compile_stmt.

2️⃣ كتل دوال الملفات أُدخلت بعد "return code" (كود ميت):
   كود فتح/اكتب_ملف/اقرأ_ملف/اختم كان بعد return code الخاص
   بحالة نص literal — فلا يُنفَّذ أبداً → "دالة غير معرفة".
   الحل: أُعيد إدخالها قبل فحص locals/globals في قسم استدعاء
   الدوال المعرفة، حيث تكون قابلة للوصول.

3️⃣ وسيط env_layout ناقص:
   دوال الملفات كانت تستدعي compile_expr بثلاثة وسائط
   بينما النسخة الجديدة تتطلب أربعة (env_layout).
   الحل: أُضيف env_layout لكل استدعاء.

4️⃣ أعلام فتح الملف:
   كانت 577 = O_WRONLY|O_CREAT|O_TRUNC — ففتح الملف للقراءة
   يمسحه (O_TRUNC → 0 بايت + segfault).
   الحل: 66 = O_RDWR|O_CREAT — قراءة وكتابة دون مسح.
