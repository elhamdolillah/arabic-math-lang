# المُجمّع AOT للغة العربية الرياضية

**مشروع مكتمل: من المرحلة 22b إلى المرحلة 38 — كل المراحل نجحت 6/6 ✅**

مشروع بحثي طموح: لغة برمجة مكتوبة بالعربية مع رموز رياضية، يُجمَّع Ahead-of-Time (AOT) إلى ملف ELF مستقل تمامًا على x86_64 Linux **بدون أي مكتبة خارجية (بدون libc)**، باستخدام syscalls الخام (`sys_write=1`, `sys_exit=60`, `sys_open=2`, `sys_socket=41`...) عبر NASM و LD. الإنجاز الأعظم: **المُجمّع نفسه مكتوب بلغتنا العربية** (Bootstrap ذاتي 100%).

## بنية كل مجلد مرحلة

كل مجلد `stageNN/` يحتوي:

| الملف | الشرح |
|---|---|
| `math_complete.py` | محرك المُجمّع: يُحلّل اللغة العربية الرياضية ويولّد كود Assembly x86_64 كاملًا |
| `phaseNN.py` | سكريبت اختبار المرحلة: برامج مكتوبة بلغتنا، تُجمَّع وتُنفَّذ وتُقارن بالنتائج المتوقعة |
| `result_stageNN_to_copy.txt` | التقرير العربي النهائي الجاهز للنسخ (إصلاحات + جدول نتائج + القدرات) |
| `result_stageNN.stdout` | سجل التنفيذ الكامل للتشغيل |
| `*.asm` | كود Assembly المولّد لكل برنامج اختبار |
| `*` (بدون امتداد، ELF) | الملفات التنفيذية المستقلة بلا libc |
| ملفات `.txt` ناتجة | بيانات الاختبارات (مثل `generated_text.txt`، `knowledge_base.txt`، `neural_net.txt`) |
| `NOTES_*.md` | ملاحظات التشخيص والإصلاحات |

## ملخص الإنجاز التقني

- **Bootstrap ذاتي 100%**: المحرّك المولّد مكتوب بلغتنا العربية نفسها.
- **ELF مستقل بلا libc**: كل البرامج تعمل بـ syscalls خام فقط (لا رابط ديناميكي).
- **تغطّى**: الحسابيات، النصوص UTF-8، الشرط والحلقات، الملفات، الشبكات، القوائم والجداول وSQL، AI الرمزي، الجبر الخطي، التفاضل والتكامل الرمزي، الشبكات العصبية، التعلم الرمزي، NLP عربي كامل، وتوليد النصوص.
- **أخطاء حقيقية صُحّحت عبر المراحل**: overflow buffer في تحويل الأرقام، حماية rcx عبر syscalls، تسميات مكررة، مقارنة سلاسل بالمحتوى (str_eq)، إزاحة رؤوس الطول، والأرقام السالبة في نص().
