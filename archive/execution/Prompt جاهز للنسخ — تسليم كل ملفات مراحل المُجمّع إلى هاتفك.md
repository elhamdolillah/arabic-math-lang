# Prompt جاهز للنسخ — تسليم كل ملفات مراحل المُجمّع إلى هاتفك

انسخ النص التالي كاملاً والصقه في محادثة جديدة مع Manus في نفس المشروع (أو في أي محادثة جديدة):

---

لدي مشروع مكتمل باسم "المُجمّع AOT للغة العربية الرياضية" (من المرحلة 22b حتى المرحلة 38) موجود في مجلدات `/home/ubuntu/work/math_aot_stage*_test/`. أريد منك الآن القيام بما يلي بدقة:

**1. بناء أرشيف شامل باسم `arabic_math_compiler_all_stages.zip`** يضم كل مجلدات المراحل مع ملف README شامل باللغة العربية يحتوي على:
   - فهرس بكل المراحل (22b → 38) وماذا تحقق في كل مرحلة (مثال: المرحلة 30 = AI الرمزي، المرحلة 35 = شبكات عصبية، المرحلة 37 = NLP عربي، المرحلة 38 = توليد نصوص).
   - شرح بنية كل مجلد: ما هو `math_complete.py` (محرك المُجمّع الذي يولّد Assembly x86_64 من لغة عربية ويُجمَّع بـ NASM/LD إلى ELF مستقل بلا libc)، وما هي ملفات `phaseN.py` (سكريبتات الاختبار)، وملفات `result_stageN_to_copy.txt` (التقارير العربية الجاهزة للنسخ)، وملفات `*.asm` (كود Assembly المولّد)، وملفات التنفيذ الثنائية ELF، وملفات الناتج مثل `generated_text.txt`.
   - تعليمات قصيرة: كيف يشغّل المستخدم أي مرحلة على Linux (python3 phaseN.py)، وشروط التشغيل (nasm + ld مثبتان).
   - ملخص الإنجاز: Bootstrap 100%، توليد ELF مستقل باستخدام syscalls خام، وكل المراحل 6/6 ✅.

**2. رفع الأرشيف** إلى رابط عام قابل للتنزيل المباشر على الهاتف (مثل: رابط مباشر بدون صفحة وسيطة)، وامنحنى الرابط في رسالة واحدة واضحة.

**3. إذا كنت لا تستطيع رفع ZIP كامل، وزّع الملفات على عدة أرشيفات أصغر** (مثلاً كل 5 مراحل في ملف) مع قائمة روابط واضحة.

**4. أرفق في رسالتك أيضاً** نسخة منفصلة من جميع ملفات `result_stage*_to_copy.txt` (تقارير النجاح الجاهزة للنسخ) حتى أطلع عليها مباشرة دون فك الضغط.

نفّذ كل هذا في sandbox وسلّم النتيجة بروابط جاهزة للنقر على الهاتف.

# هل الإرسال إلى Git مفيد؟ نعم، وبشدة

**الجواب: نعم — أنصحك بشدة برفع المشروع إلى GitHub (أو GitLab).** الأسباب:

| الفائدة | الشرح |
|---|---|
| حفظ دائم | ملفات Sandbox قد تُنظَّف مع الوقت؛ Git يحفظ كل شيء للأبد وبمجان |
| تاريخ التدرج | كل مرحلة = commit بموعد ووصف → ترى رحلة المشروع كاملة من المرحلة 22b إلى 38 |
| مشاركة | يمكن لأي شخص استنساخ المشروع وتشغيله: `git clone` ثم `python3 phaseN.py` |
| نسخ احتياطية | إذا فقدت هاتفك أو حاسوبك، المشروع باقٍ في السحابة |
| إثبات الإنجاز | رابط GitHub حي يوثّق إنجازك في محادثاتك أو سيرتك |

**توصية عملية:**
1. أنشئ مستودعاً باسم مثل `arabic-math-compiler` على GitHub.
2. استخدم prompt إضافي مع Manus:

> «أنشئ مستودع GitHub باسم arabic-math-compiler، وارفع فيه كل مجلدات المراحل /home/ubuntu/work/math_aot_stage*_test/ مع README عربي يشرح المشروع، مع ملف .gitignore (تجاهل ملفات .o المؤقتة)، وcommit واحد لكل مرحلة (أو كل 3-4 مراحل) مع رسالة تصف الإنجاز.»

3. إذا لم يكن حسابك مربوطاً بـ Manus، يمكنك بدلاً من ذلك تنزيل الـ ZIP على هاتفك ورفعه يدوياً عبر موقع GitHub.

**ملاحظة أمان:** لا تحتوي ملفاتك على أي مفاتيح سرية (فهي كود مفتوح المصدر بطبيعته)، فلا مانع من جعل المستودع **Public** — وهذا الأفضل لمشروع بهذا الطابع التعليمي/البحثي.
