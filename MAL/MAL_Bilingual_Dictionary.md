# 📚 قاموس ومفردات مشروع MAL الثنائي اللغة (عربي - English)
## ⚠️ القاعدة الذهبية للمحلل (The Golden Parser Rule)
**العربية:** في لغة MAL، يجب أن يكون تعريف المصفوفة وتعبئتها بالقيم **في سطر واحد فقط** ينتهي بفاصلة منقوطة `;`. المحلل الحالي (Parser) يقرأ الكود سطراً بسطر، لذا فإن توزيع المصفوفة على أسطر متعددة يؤدي إلى فشل في التعرف على نهاية البيان وتوليد كود C خاطئ.
**English:** In MAL, array definitions and initializations **must be on a single line** ending with a semicolon `;`. The current parser reads line-by-line, so multiline arrays cause parsing failures and incorrect C code generation.

## 🌉 القاموس السياقي (Contextual Dictionary)
| المصطلح العربي | English Term | السياق والتعريف في مشروع MAL |
| :--- | :--- | :--- |
| **مترجم MAL** | `malc` Compiler | المترجم المخصص الذي يحول كود لغة MAL إلى كود C ثم إلى ملف تنفيذي أصلي (Native Binary). |
| **التوليد التلقائي** | Autoregressive Generation | آلية توليد النص حرفاً بحرف (أو رمزاً برمز)، حيث يُستخدم مخرج الخطوة الحالية كمدخل للخطوة التالية. |
| **آلة الحالات المحدودة** | Deterministic Finite Automaton (DFA) | النموذج المنطقي المستخدم لحل مشكلة تكرار الأحرف (مثل "Helo") عن طريق استخدام "عداد الخطوات" (Step Counter) كحالة بدلاً من الرمز السابق. |
| **عداد الخطوات** | Step Counter | المتغير المستخدم كحالة (State) في نموذج التوليد لضمان التقدم التسلسلي الصحيح عبر مصفوفة الأوزان دون تكرار. |
| **المُرمِّز على مستوى الأحرف** | Character-level Tokenizer | الوحدة المسؤولة عن تحويل الأحرف إلى رموز رقمية (ASCII codes) والعكس، كخطوة أولى لفهم اللغة. |
| **المرور الأمامي** | Forward Pass | عملية حسابية تمرر البيانات عبر طبقات الشبكة العصبية من المدخلات إلى المخرجات لحساب النتيجة النهائية. |
| **صفر اعتماديات** | Zero Dependencies | القدرة على تشغيل النموذج المُجمَّع بدون الحاجة إلى Python، PyTorch، أو أي مكتبات خارجية. |
| **الحتمية المطلقة** | Absolute Determinism | ضمان أن يعطي النموذج نفس المخرجات الرقمية بالضبط (Bit-exact) في كل مرة يتم فيها التشغيل، بغض النظر عن البيئة. |
| **تطبيع الطبقة** | Layer Normalization (LayerNorm) | خوارزمية تعمل على تثبيت متوسط وتباين المخرجات داخل الطبقة العصبية لتحسين استقرار التدريب والاستدلال. |
| **دالة التنشيط الاحتمالي** | Softmax Function | دالة رياضية (تستخدم `expf`) تحول المخرجات الخام (Logits) إلى توزيع احتمالي مجموع قيمه يساوي 1.0. |
| **الانتباه متعدد الرؤوس** | Multi-Head Attention | بنية متقدمة تسمح للنموذج بالتركيز على أجزاء مختلفة من تسلسل المدخلات في آن واحد عبر تقسيم الأبعاد إلى "رؤوس". |
| **توجيهات التحسين** | Compiler Directives (SIMD / Unroll) | أوامر مثل `#unroll` و `#simd` المضافة لكود MAL لتوجيه مترجم GCC لفك الحلقات واستخدام تعليمات المعالج المتجهة لتسريع الأداء. |
| **أعلام البناء القصوى** | Extreme Build Flags | المعاملات `-O3 -march=native -ffast-math -lm` المضافة لـ GCC لتحقيق أقصى سرعة حسابية وربط مكتبة الرياضيات. |
| **الكمية (تكميم البيانات)** | Quantization (e.g., `i8`) | تقنية مقترحة لتقليل حجم نموذج MAL وسرعة تنفيذه عن طريق تحويل الأوزان من `f32` إلى أعداد صحيحة `i8`. |
| **مصفوفات الأوزان المدمجة** | Embedded Weight Matrices | تخزين أوزان النموذج المدربة مباشرة داخل كود مصدر MAL كمصفوفات ثابتة `[f32; N]` لضمان السرعة والحتمية. |
| **عد الأقواس** | Brace Counting | الخوارزمية المصححة داخل المحلل لتحديد بداية ونهاية الكتل البرمجية (مثل الدوال وحلقات `if/while`) بدقة. |

## 🎯 الخلاصة الهندسية
هذا القاموس ليس مجرد قائمة ترجمة، بل هو **مرجع سياقي (Contextual Reference)** يربط المفاهيم النظرية للذكاء الاصطناعي بكيفية تنفيذها فعلياً داخل بنية مترجم `malc` المخصص، مما يسهل تطوير اللغة أو تدريب نماذج مستقبلية عليها.
