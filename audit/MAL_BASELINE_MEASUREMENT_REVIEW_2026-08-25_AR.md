**التاريخ:** 2026-08-25  
**الفرع:** `integration/mal-deterministic-audit-2026-08-25`  
**نطاق القياس:** جذر مستودع UORI، مع استبعاد المسارات التي تستبعدها أداة القياس افتراضيًا  
**أداة القياس:** `scripts/uori_language_ratio_deterministic.py`، الإصدار `1.1.0-deterministic`

## الحكم التنفيذي

تم تثبيت حالة Git محليًا ثم تشغيل أداة القياس الرسمية على الشجرة الحالية. الأرقام أدناه **مقاسة فعليًا** وليست توقعات. لا تثبت هذه الأرقام وجود مشغل MAL ولا الاكتفاء الذاتي؛ إنها قياس لحجم المصدر فقط.

```text
GIT_BASELINE_COMMIT=d187ce9
RATIO_MEASUREMENT=PERFORMED
REPORT_SHA256=5a08540ae2f432c5e26cec4a436be786d4a6edc20288d8254735799cfdb1c4a8
MAL_AR_RUNTIME=UNAVAILABLE
SOURCE_EXECUTION=NOT_PERFORMED
AUTO_PROMOTION=DENY
BASELINE_FREEZE=ACTIVE
```

## التفسير الدستوري

النسبة المستهدفة في خطة التعريب يجب فصلها عن النسبة الشاملة. المؤشر المقاس `MAL/(MAL+Python)` يساوي **2.06%** في هذه الشجرة، بينما المؤشر الشامل `MAL/ALL` يساوي **0.23%**. لا يجوز إعلان الوصول إلى 51% أو 75% أو 100% قبل إضافة ملفات فعلية وإعادة تشغيل الأداة وحفظ تقرير جديد ببصمة جديدة.

كما أن ارتفاع نسبة `.ar` لا يساوي إثبات التنفيذ. يلزم، بصورة مستقلة، parser أو interpreter موثوق، corpus، مخرجات canonical، تكافؤ تفاضلي، وسلسلة SHA-256 ناجحة قبل تغيير `SOURCE_EXECUTION` أو تصنيف أي وحدة إلى `PROVEN`.

## حالة Git

تم إنشاء الالتزام المحلي التالي لتثبيت الحالة قبل القياس:

```text
d187ce9 Establish MAL migration measurement baseline
```

الفرع المحلي متقدم عن الفرع البعيد بالتزام واحد، ولم تُجرَ عملية دفع إلى المستودع البعيد. ملفات القياس الناتجة بعد الالتزام بقيت تغييرات محلية غير ملتزم بها إلى حين مراجعتها.

## القرار

القياس **مقبول بوصفه baseline كميًا**. خطة رفع النسبة إلى 51% تبقى خطة مستقبلية، وليست نتيجة حالية. الأولوية التالية الآمنة هي اختيار وحدة Python واحدة قابلة للهجرة، تعريف عقدها في MAL، ثم بناء النظير واختبار التكافؤ؛ ولا يُستبدل الملف المرجعي أو يُحذف قبل نجاح الاختبار.

أما Rust Arena، فتبقى خارج نطاق هذه الدورة وفق القرار الحالي، ولا تُعلن بوابة المرحلة صفر مغلقة بسبب هذا القياس وحده.
