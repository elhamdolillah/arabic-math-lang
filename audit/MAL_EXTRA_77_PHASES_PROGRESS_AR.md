# تقرير تقدم الدفعة الإضافية من خارطة MAL

## النطاق

يشمل هذا التقرير العقود الجديدة للتحويل والتطبيع بين AST وIR، والتوليد وABI، وتدقيق الذاكرة والحدود، واختبارَي الإعادة. لا يشمل تشغيل مصدر MAL؛ إذ لم يثبت توافر مشغل MAL موثوق.

## النتائج

| المجال | الحالة |
|---|---|
| عقد AST–IR والتطبيع | `PASS` بنيوي؛ التصنيف `POLICY/RESEARCH` |
| عقد Codegen وABI | `PASS` بنيوي؛ الترتيب `ordinal` تصاعدي |
| حظر المؤشرات الخام والجدولة | `DENY` حسب العقد |
| حدود الذاكرة والفيض والتخصيص اللاحق | `ABSTAIN` عند الانتهاك |
| اختبارا الإعادة | `REPRO_RUNS=2` |
| تطابق manifest | `MANIFEST_BYTE_IDENTICAL=YES` |
| بصمة manifest في التشغيلين | `71a97cf9921102d138a01431fa0b853ae949f16a6eb9f2e9b1baf7cb2d812c79` |
| تنفيذ source_ref | `NO` |
| baseline | `BASELINE_MODIFIED=NO` |
| الترفيع | `AUTO_PROMOTION=DENY` |

## القرار الدستوري

تثبت النتائج سلامة القياس البنيوي وقابلية إعادة إنتاج manifest، ولا تثبت التكافؤ التنفيذي أو صلاحية المشغل. لذلك لا تُرفع العقود إلى `PROVEN`، ولا يُنتج artifact تنفيذي من مصدر غير موثوق. يبقى المسار التنفيذي `ABSTAIN_UNTIL_EVIDENCE` إلى أن تتوافر نواة MAL قابلة للتحقق.
