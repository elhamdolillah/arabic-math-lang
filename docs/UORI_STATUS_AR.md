# الحالة الموثقة لمنظومة UORI

[العودة إلى خريطة UORI](UORI_OVERVIEW_AR.md)

## قاعدة القراءة

هذا الملف يصف حالة المستودع في لحظة التسجيل، ولا يستبدل سجلات الاختبارات أو البصمات. النجاح في اختبار محدد يثبت ذلك الاختبار فقط؛ ولا يثبت اكتمال المنظومة أو تشغيلها على عتاد حقيقي.

| المجال | الحالة الموثقة | حدود الادعاء |
|---|---|---|
| لغة UORI العربية الرياضية | مكونات مترجم واختبارات موجودة | لا يثبت ذلك جمع كل اللغات أو اكتمال المواصفة |
| LLM الحتمي | هدف بحثي/معماري | لا يوجد في هذا المستودع وحده دليل على نموذج حتمي مكتمل |
| UORI OS | runtime/syscall وعقود قيد التحقق | لا يثبت ذلك نظام تشغيل قابلاً للإقلاع على bare metal |
| UORI Global APK | هدف مخطط | يلزم بناء APK واختبار تثبيت وتشغيل مستقلان |
| التحقق الرسمي | جزئي بحسب ملفات Coq المتاحة | لا يساوي إثبات التنفيذ الكامل أو العتاد |

## سياسة الحالة

عند غياب ملف اختبار أو عقد أو سجل بصمة، تكون الحالة **ممتنعاً عن التصنيف** بدلاً من استنتاج النجاح. وعند وجود نموذج أو ملف تجريبي، يستخدم وصف **نموذج أولي** أو **قيد الاختبار**. وتُحجز كلمة **مثبت** للنتائج التي يمكن لمراجع مستقل إعادة تشغيلها والتحقق من بصمتها.
