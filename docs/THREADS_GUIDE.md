## 🧵 Threads (الخيوط)

### إنشاء خيط

```arabic
# تعريف دالة العامل
عامل ≡ λ(). ﴿
    ⎕ "مرحباً من الخيط!"
﴾

# إنشاء وتشغيل
خ ≔ خيط(عامل)

# الانتظار حتى الانتهاء
انتظر(خ)
```

### مثال: عاملَين متوازيان

```arabic
عامل١ ≡ λ(). ﴿
    ع ≔ 1
    ⋄ μ ع <= 5 : ﴿
        ⎕ "خيط 1: " ⊕ نص(ع)
        ⋄ ع ≔ ع + 1
    ﴾
﴾

عامل٢ ≡ λ(). ﴿
    ع ≔ 1
    ⋄ μ ع <= 5 : ﴿
        ⎕ "خيط 2: " ⊕ نص(ع)
        ⋄ ع ≔ ع + 1
    ﴾
﴾

خ١ ≔ خيط(عامل١)
خ٢ ≔ خيط(عامل٢)

انتظر(خ١)
انتظر(خ٢)
```

## 📡 Channels (القنوات)

### الأساسيات

```arabic
# إنشاء قناة
ق ≔ قناة()

# الإرسال
أرسل(ق، 42)

# الاستقبال
قيمة ≔ استقبل(ق)
⎕ قيمة    # 42
```

### مثال: منتج ومستهلك

```arabic
ق ≔ قناة()

# المنتج
منتج ≡ λ(). ﴿
    ع ≔ 1
    ⋄ μ ع <= 5 : ﴿
        ⎕ "إنتاج: " ⊕ نص(ع)
        ⋄ أرسل(ق، ع)
        ⋄ ع ≔ ع + 1
    ﴾
    ⋄ أرسل(ق، 0)  # إشارة الانتهاء
﴾

# المستهلك
مستهلك ≡ λ(). ﴿
    μ 1 = 1 : ﴿
        قيمة ≔ استقبل(ق)
        ⋄ قيمة = 0 ؟ ﴿ ⎕ "انتهى" ﴾ : ﴿ ⎕ "استلام: " ⊕ نص(قيمة) ﴾
    ﴾
﴾

خ١ ≔ خيط(منتج)
خ٢ ≔ خيط(مستهلك)
انتظر(خ١)
انتظر(خ٢)
```

## 🔒 Mutexes (المزاليج)

### الأساسيات

```arabic
# إنشاء مزلاج
قفل ≔ مزلاج()

# المنطقة الحرجة
أغلق(قفل)
# ... عمليات على بيانات مشتركة ...
افتح(قفل)
```

### مثال: عداد آمن

```arabic
قفل ≔ مزلاج()
عداد ≔ 0

# دالة آمنة للزيادة
زيادة ≡ λ(). ﴿
    أغلق(قفل)
    ⋄ عداد ≔ عداد + 1
    ⋄ افتح(قفل)
﴾

# 100 خيط يزيدون العداد
ع ≔ 1
μ ع <= 100 : ﴿
    خيط(زيادة)
    ⋄ ع ≔ ع + 1
﴾

# الانتظار
# ... (انتظار كل الخيوط)

⎕ "العداد: " ⊕ نص(عداد)  # يجب أن يكون 100
```

## 🎯 أنماط شائعة

### نمط 1: Worker Pool

```arabic
# طابور مهام
مهام ≔ قناة()
نتائج ≔ قناة()

# العمال (4 عمال)
عامل ≡ λ(). ﴿
    μ 1 = 1 : ﴿
        مهمة ≔ استقبل(مهام)
        ⋄ نتيجة ≔ مهمة · 2  # معالجة
        ⋄ أرسل(نتائج، نتيجة)
    ﴾
﴾

ع ≔ 1
μ ع <= 4 : ﴿
    خيط(عامل)
    ⋄ ع ≔ ع + 1
﴾

# إضافة مهام
ع ≔ 1
μ ع <= 10 : ﴿
    أرسل(مهام، ع)
    ⋄ ع ≔ ع + 1
﴾

# جمع النتائج
ع ≔ 1
μ ع <= 10 : ﴿
    نتيجة ≔ استقبل(نتائج)
    ⋄ ⎕ نتيجة
    ⋄ ع ≔ ع + 1
﴾
```

### نمط 2: Pipeline

```arabic
# مرحلة 1: توليد
ق١ ≔ قناة()
خ١ ≔ خيط(λ(). ﴿ ... ﴾)

# مرحلة 2: معالجة
ق٢ ≔ قناة()
خ٢ ≔ خيط(λ(). ﴿
    μ 1 = 1 : ﴿
        قيمة ≔ استقبل(ق١)
        ⋄ نتيجة ≔ قيمة · 2
        ⋄ أرسل(ق٢، نتيجة)
    ﴾
﴾)

# مرحلة 3: إخراج
خ٣ ≔ خيط(λ(). ﴿
    μ 1 = 1 : ﴿
        قيمة ≔ استقبل(ق٢)
        ⋄ ⎕ قيمة
    ﴾
﴾)
```

### نمط 3: Map-Reduce

```arabic
# Map: معالجة كل عنصر في خيط مستقل
قائمة ≔ ⟨1, 2, 3, 4, 5⟩
نتائج ≔ قناة()

∀ ع ∈ قائمة : ﴿
    خيط(λ(). ﴿
        أرسل(نتائج، ع · ع)
    ﴾)
﴾

# Reduce: جمع النتائج
مجموع ≔ 0
ع ≔ 1
μ ع <= 5 : ﴿
    مجموع ≔ مجموع + استقبل(نتائج)
    ⋄ ع ≔ ع + 1
﴾

⎕ "المجموع: " ⊕ نص(مجموع)  # 55
```

## ⚠️ المزاليج الشائعة

### 1. Deadlock (الجمود)

```arabic
# ❌ خطأ: dead lock
قفل١ ≔ مزلاج()
قفل٢ ≔ مزلاج()

# خيط 1
أغلق(قفل١)
أغلق(قفل٢)  # قد ينتظر إلى الأبد
افتح(قفل٢)
افتح(قفل١)

# الحل: ترتيب ثابت للأقفال
```

### 2. Race Condition

```arabic
# ❌ خطأ: race condition
عداد ≔ 0

عامل ≡ λ(). ﴿
    ع ≔ 1
    ⋄ μ ع <= 1000 : ﴿
        عداد ≔ عداد + 1  # غير آمن!
        ⋄ ع ≔ ع + 1
    ﴾
﴾

# الحل: استخدام مزلاج
```

## 📊 الأداء

### مقارنة

| النمط | الخيوط | الوقت (μs) |
|-------|--------|------------|
| متسلسل | 1 | 1000 |
| متوازي (4) | 4 | 280 |
| متوازي (8) | 8 | 160 |

### نصائح الأداء

1. **تجنب الإفراط في الخيوط** — لا تنشئ أكثر من عدد النوى
2. **استخدم Channels** بدلاً من Mutexes حيث أمكن
3. **قلل المناطق الحرجة** — اجعلها قصيرة قدر الإمكان
4. **استخدم Work Stealing** للمهام غير المتوازنة
