# لغة UORI العربية الرياضية

[العودة إلى خريطة UORI](UORI_OVERVIEW_AR.md)

## الغرض

لغة UORI العربية الرياضية هي الطبقة التي تجعل الصياغة العربية واجهة برمجية أصلية، لا مجرد ترجمة سطحية. تستوعب الطبقة مفاهيم من لغات مختلفة، مثل الأنواع الجبرية والملكية الخطية والسمات والتطابق النمطي، ثم تعيد تنظيمها في نحو عربي وعقود قابلة للاختبار.

## المسار التنفيذي الموثق

```text
مصدر عربي → Lexer → Parser → AST → فحص الأنواع والملكية → CodeGen → Assembly/هدف تنفيذي
```

توجد في المستودع ملفات مترجم واختبارات ومراجع نحوية. ويجب اعتبار كل ميزة مثبتة فقط بقدر ما تغطيه اختبارات قابلة لإعادة التشغيل وسجلات أدلة مرتبطة بها.

## العلاقة بالمحاور الأخرى

تنتج اللغة تمثيلاً مضبوطاً يمكن لطبقة LLM أن تشرحه أو تقترح له فرضيات، ويمكن للمترجم أن يمرره إلى runtime وABI، ويمكن لواجهة APK أن تعرضه للمستخدم. ولا تمنح اللغة وحدها دليلاً على وجود LLM حتمي أو نظام تشغيل مكتمل.

## الحالة

**الحالة: مثبت جزئياً/قيد التحقق.** توجد مكونات واختبارات في المستودع، لكن عبارة «تجمع كل لغات العالم» هدف تصميمي واسع وليست نتيجة مثبتة بمجرد وجود المترجم الحالي.
