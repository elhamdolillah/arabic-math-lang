# مرجع القواعد النحوية للغة MAL

## 1. التعابير الجبرية
- الجمع: `+`
- الطرح: `-`
- الضرب: `*` أو `·`
- القسمة: `/` أو `÷`
- الأس: `^`
- الجذر: `sqrt(تعبير)`
- اللوغاريتم: `log(قاعدة, قيمة)`
- الدوال المثلثية: `sin`, `cos`, `tan`

## 2. التفاضل والتكامل
- التفاضل: `تفاضل(تعبير, متغير)`
- التكامل غير المحدد: `تكامل(تعبير, متغير)`
- التكامل المحدد: `تكامل(تعبير, متغير, من, إلى)`

## 3. المصفوفات
- تعريف مصفوفة: `مصفوفة([[...]])`
- العمليات: `ضرب_مصفوفات`, `محدد`, `معكوس_مصفوفة`

## 4. المعادلات التفاضلية
- `حل_معادلة_تفاضلية ( معادلة: ..., شرط_ابتدائي: [س0: ..., ص0: ...] )`

## 5. الشروط المنطقية
- `إذا (شرط) { ... } وإلا { ... }`

## 6. حل المعادلات الجبرية
- `حل_معادلة(تعبير, متغير)` → حل معادلة جبرية (مثل `س^2 - 4 = 0`).

## 7. التكامل والاشتقاق العددي
- `تكامل_عددي(دالة, متغير, من, إلى)` → تكامل عددي (طريقة سيمبسون).
- `اشتقاق_عددي(دالة, متغير, نقطة)` → اشتقاق عددي (فروق مركزية).

## 8. عمليات المصفوفات المتقدمة
- `معكوس_مصفوفة(مصفوفة)` → معكوس المصفوفة (إن وجد).
- `محدد(مصفوفة)` → محدد المصفوفة.
- `حل_نظام(مصفوفة_معاملات, متجه_الثوابت)` → حل نظام خطي.

## 9. دوال خاصة
- `غاما(قيمة)` → دالة غاما.
- `بيتا(قيمة1, قيمة2)` → دالة بيتا.

## 10. الدوال المثلثية العكسية والزائدية
- `asin(x)`, `acos(x)`, `atan(x)` → دوال مثلثية عكسية.
- `sinh(x)`, `cosh(x)`, `tanh(x)` → دوال زائدية.
