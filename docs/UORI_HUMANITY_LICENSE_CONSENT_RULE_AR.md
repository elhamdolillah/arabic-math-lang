# قاعدة الموافقة والترخيص لصالح البشرية في UORI

## 1. النص المعياري المقترح

إذا وافق مطوّر أو صاحب حقوق مخوّل على دمج خوارزميته ضمن UORI لإتاحتها للعالم، وجب أن تكون الموافقة صريحة وقابلة للإثبات، وأن تحدد أن الخوارزمية ستتاح للمنفعة البشرية العامة وفق ترخيص منشور وواضح. ولا تُفهم عبارة «تصبح ملكاً للبشرية» تلقائياً بوصفها نقلاً قانونياً للملكية في كل دولة؛ بل تُنفذ عبر ترخيص أو تنازل حقوقي صريح يحدد الحقوق التي مُنحت لـ UORI ولعموم المستفيدين.

## 2. شروط الموافقة

لا تقبل UORI الخوارزمية في المسار العام لمجرد رسالة غير موثقة. يجب أن يسجل صاحب الحق هويته أو صفته التمثيلية، ومعرف الخوارزمية وإصدارها، ونطاق الحقوق الممنوحة، وطبيعة الإتاحة، والقيود، وأحكام النسبة، ومصدر الكود أو المواصفة، وتاريخ الموافقة، وبصمة المحتوى المرخص. ويوقع السجل أو يثبت بوسيلة تحقق مناسبة، ثم يمر عبر بوابة القبول والفحص الأمني.

| العنصر | الحد الأدنى |
|---|---|
| صاحب الموافقة | مطور أو صاحب حقوق مخوّل |
| موضوع الموافقة | خوارزمية وإصدار وبصمة محددة |
| الغرض | إتاحة بشرية عامة أو نطاق صريح آخر |
| الحقوق | تشغيل، دراسة، تعديل، إعادة توزيع بحسب الترخيص |
| القيود | مصرح بها ومعلنة قبل القبول |
| التاريخ | وقت إصدار قابل للتدقيق |
| الدليل | توقيع أو سجل موافقة وبصمة SHA-256 |

## 3. مبدأ المنفعة البشرية

بعد استيفاء الموافقة والترخيص والفحص، تُعامل الخوارزمية المقبولة باعتبارها مورداً متاحاً للمنفعة البشرية العامة ضمن شروط ترخيصها. ولا تعني الإتاحة أن الخوارزمية آمنة لكل عتاد أو مناسبة لكل استعمال؛ فكل ادعاء سلامة أو كفاءة يبقى مقيداً بأدلته ونطاقه، وتظل آلية الإلغاء والعزل واجبة.

## 4. سحب الموافقة والتعارض

تسجل UORI أي سحب أو تعديل أو نزاع في الحقوق، وتوقف الإصدارات المتأثرة عن التوزيع الجديد عند الحاجة، وتحافظ على سجل تاريخي غير مضلل. ولا تمحو البصمة التاريخية أو تعيد كتابة الوقائع؛ بل تنشر حالة الإصدار الجديدة، وتطبق أحكام الترخيص السارية على النسخ السابقة وفقاً للسجل القانوني الموثق.
