## 📖 المبادئ الثمانية

### 1️⃣ الإحكام (Precision)

> **«كِتَابٌ أُحْكِمَتْ آيَاتُهُ»** — سورة هود، الآية 1

**التعريف الرياضي:**
```
∀ رمز س ∈ Σ: |تفسير(س)| = 1
```

**التطبيق:**
- كل رمز له معنى واحد محدد لا لبس فيه
- لا ambiguity، لا implicit conversions
- الوضوح التام في الدلالات

**الأساس الشرعي:**
> **«وَلَا تَلْبِسُوا الْحَقَّ بِالْبَاطِلِ»** — سورة البقرة، الآية 42

---

### 2️⃣ التيسير (Simplicity)

> **«وَلَقَدْ يَسَّرْنَا الْقُرْآنَ لِلذِّكْرِ فَهَلْ مِن مُّدَّكِرٍ»** — سورة القمر، الآية 17

**التعريف الرياضي:**
```
|Σ| = 20 رمز (Turing-complete basis)
```

**التطبيق:**
- 20 رمزًا أساسيًا فقط تكفي لكل البرامج
- حمل إدراكي أدنى (minimal cognitive load)
- سهولة التعلم والاستخدام

**الأساس الشرعي:**
> **«يُرِيدُ اللَّهُ بِكُمُ الْيُسْرَ وَلَا يُرِيدُ بِكُمُ الْعُسْرَ»** — سورة البقرة، الآية 185

---

### 3️⃣ العدل (Balance)

> **«إِنَّ اللَّهَ يَأْمُرُ بِالْعَدْلِ وَالْإِحْسَانِ»** — سورة النحل، الآية 90

**التعريف الرياضي:**
```
∀ ميزة م: ثمن(م) > 0 ∧ فائدة(م) > ثمن(م)
```

**التطبيق:**
- لا ميزة بلا ثمن (no free lunch)
- كل ميزة لها تكلفة واضحة ومبررة
- التوازن بين القوة والتعقيد

**الأساس الشرعي:**
> **«وَالسَّمَاءَ رَفَعَهَا وَوَضَعَ الْمِيزَانَ»** — سورة الرحمن، الآية 7

---

### 4️⃣ الأمانة (Ownership)

> **«إِنَّ اللَّهَ يَأْمُرُكُمْ أَن تُؤَدُّوا الْأَمَانَاتِ إِلَىٰ أَهْلِهَا»** — سورة النساء، الآية 58

**التعريف الرياضي:**
```
∀ مورد ر، ∀ لحظة ز: ∃! مالك م: يملك(م، ر، ز)
```

**التطبيق:**
- Linear Ownership — كل مورد له مالك واحد
- نقل الملكية صريح عبر ⊸
- لا use-after-move، لا double-free

**الأساس الشرعي:**
> **«يَا أَيُّهَا الَّذِينَ آمَنُوا لَا تَخُونُوا اللَّهَ وَالرَّسُولَ وَتَخُونُوا أَمَانَاتِكُمْ»** — سورة الأنفال، الآية 27

---

### 5️⃣ البيان (Transparency)

> **«هَٰذَا بَيَانٌ لِّلنَّاسِ وَهُدًى وَمَوْعِظَةٌ لِّلْمُتَّقِينَ»** — سورة آل عمران، الآية 138

**التعريف الرياضي:**
```
∀ عملية ع: ∃ توثيق(ع) ∧ قابلة_للفحص(ع)
```

**التطبيق:**
- كل عملية موثقة وقابلة للفحص
- رسائل خطأ واضحة مع السطر والعمود
- شفافية كاملة في التنفيذ

**الأساس الشرعي:**
> **«قَدْ تَبَيَّنَ الرُّشْدُ مِنَ الْغَيِّ»** — سورة البقرة، الآية 256

---

### 6️⃣ الحفظ (Safety)

> **«إِنَّا نَحْنُ نَزَّلْنَا الذِّكْرَ وَإِنَّا لَهُ لَحَافِظُونَ»** — سورة الحجر، الآية 9

**التعريف الرياضي:**
```
∀ برنامج ب: جمّع(ب) ⟹ آمن_ذاكرة(نفّذ(ب))
```

**التطبيق:**
- أمان الذاكرة مضمون بالبناء (by construction)
- Bounds checking لكل المصفوفات
- لا null pointer، لا buffer overflow

**الأساس الشرعي:**
> **«وَلَا تُلْقُوا بِأَيْدِيكُمْ إِلَى التَّهْلُكَةِ»** — سورة البقرة، الآية 195

---

### 7️⃣ التفكر (Verifiability)

> **«أَفَلَا يَتَدَبَّرُونَ الْقُرْآنَ»** — سورة النساء، الآية 82

**التعريف الرياضي:**
```
∀ خطأ خ: قابل_للتجنب(خ) ⟹ يُكتشف_في_التجميع(خ)
```

**التطبيق:**
- كل الأخطاء القابلة للتجنب تُكتشف في وقت التجميع
- Type checking صارم
- Ownership checking في وقت التجميع

**الأساس الشرعي:**
> **«قُلْ هَاتُوا بُرْهَانَكُمْ إِن كُنتُمْ صَادِقِينَ»** — سورة البقرة، الآية 111

---

### 8️⃣ الشمولية وإعادة الإنتاج الذاتي (Universality)

> **«وَمَا أَرْسَلْنَاكَ إِلَّا كَافَّةً لِّلنَّاسِ»** — سورة سبأ، الآية 28

**التعريف الرياضي:**
```
∀ تقنية ت ∈ {تقنيات لغات البرمجة العالمية}:
  case حالة(ت):
    مدموجة(ت)    → تجاوز(ت)
    جوهرية(ت)    → أعد_إنتاج(ت، كود_لغتنا)
    هامشية(ت)    → تجاهل(ت)
```

**النص الكامل:**
> **«خُذْ كُلَّ تِقْنِيَةٍ مِنْ لُغَاتِ الْبَرْمَجَةِ فِي الْعَالَمِ، فَإِنْ لَمْ تَكُنْ مُنْدَمِجَةً فَأَعِدْ إِنْتَاجَهَا بِكُودِ لُغَتِنَا، وَإِنْ كَانَتْ مَوْجُودَةً فَتَجَاوَزْهَا لِتَفَادِي التَّكْرَارِ»**

**التطبيق:**
- استيعاب أحسن ما في Rust, Haskell, OCaml, Go
- إعادة إنتاج ذاتية (لا استيراد)
- تجاوز التقنيات المتكررة

**الأساس الشرعي:**
> **«الْحِكْمَةُ ضَالَّةُ الْمُؤْمِنِ»** — حديث شريف

## 🌍 التقنيات: مُدمَجة vs متجاوزة

### ✅ مُدمَجة (أعدنا إنتاجها)

| التقنية | المصدر | حالتنا | الآية/الحديث |
|---------|--------|--------|--------------|
| Linear Ownership | Rust | ⊸ | «أَدُّوا الْأَمَانَاتِ» |
| Arena Allocator | C/Zig | ✅ | «وَلَا تُسْرِفُوا» |
| Closures | Lambda Calculus | λ | «وَعَلَّمَ آدَمَ الْأَسْمَاءَ» |
| Channels | Go | pipe2 | «وَتَعَاوَنُوا» |
| Generics | Haskell/ML | Parametric | «وَمَا أَرْسَلْنَاكَ إِلَّا كَافَّةً» |
| Native Threads | OS | clone | «وَجَعَلْنَاكُمْ شُعُوبًا» |
| Pattern Matching | Erlang/Rust | 7 أنماط | «فَصَّلْنَا الْآيَاتِ» |
| ADTs | Haskell/OCaml | نوع | «خَلَقَ كُلَّ شَيْءٍ فَقَدَّرَهُ» |
| Traits | Rust/Haskell | سمة | «وَرَفَعْنَا بَعْضَكُمْ فَوْقَ بَعْضٍ» |

### ❌ متجاوزة (لدينا بديل أفضل)

| التقنية | السبب | البديل |
|---------|-------|--------|
| Garbage Collection | غير متوقع، بطيء | Arena + Linear |
| Null/Undefined | مصدر أخطاء | Result/Option |
| OOP Classes | تعقيد زائد | Traits + Composition |
| Exceptions | non-local jumps | Result types |
| Reflection | أمان ضعيف | Macros (قادم) |
