# مصفوفة إثبات نطاق UORI اللامركزي

تمنع هذه المصفوفة تحويل الرؤية اللامركزية إلى ادعاء مثبت بلا قياس. لكل خاصية نطاق محدد، ودليل مطلوب، وحكم مستقل.

| الخاصية | نطاق الاختبار | الدليل المطلوب | الحكم قبل الدليل |
|---|---|---|---|
| هوية النواة | إصدار ومثيل محدد | سجل معرف وبصمة وتوقيع قابل للتحقق | `PLANNED` |
| اكتشاف النظائر | شبكة أو خلية محددة | سجلات إعلان واستجابة وتحقق | `PLANNED` |
| العضوية | فترة صلاحية ونطاق صلاحيات | سجل قبول موقّع وسجل إلغاء | `PLANNED` |
| التوازي | عدد محدد من النوى وهدف معلوم | سجل إسناد ونتائج قابلة لإعادة التشغيل | `PLANNED` |
| الاتساق | نوع عملية وعقد اتساق محدد | حالات تطابق أو حدود فترية أو معايرة احتمالية | `PLANNED` |
| التعافي | نمط انقطاع محدد | نقطة استئناف وبصمة قبل/بعد وسجل مصالحة | `PLANNED` |
| منع الانتشار | نواة أو وحدة Bridge محجورة | محاولة اختبارية وسجل رفض وقنوات معزولة | `PLANNED` |
| سلامة الموارد | حد وقت وذاكرة ورسائل وطاقة | قياسات تجاوز وإيقاف قابلة للتكرار | `PLANNED` |
| الحجم العالمي | بنية تشغيل حقيقية محددة | إحصاء مستقل للنوى الفعالة وهوياتها وأزمنتها | `ABSTAIN` |
| «مليارات الأنوية» | تعداد عالمي متصل | سجل تشغيل عام قابل للتدقيق لا عينة وصفية | `ABSTAIN` |

## قواعد الحكم

يُحكم على الخاصية حتمياً إذا كان المجال والمدخلات وحد الخطأ محددة، وفترية إذا كانت الحدود مضمونة، واحتمالياً إذا كان التوزيع مبنياً على بيانات كافية ومعايرة. وتستخدم النماذج التوليدية لاقتراح سيناريوهات الاختبار أو شرح السجلات، ولا تستخدم وحدها لإثبات الانتشار أو السلامة. عند نقص الدليل تسجل UORI `ABSTAIN` ولا تستبدلها بتقدير متفائل.

## سجل الأدلة

يجب أن يحمل كل اختبار معرفاً وإصداراً وبيئة تشغيل وبصمات المدخلات والمخرجات وسلسلة أحداث SHA-256. وتفصل السجلات بين المحاكاة، والبيئة الافتراضية، والعتاد الفعلي، والشبكة الموزعة. لا يجوز دمج نتائج هذه الطبقات في نتيجة واحدة دون التصريح بنطاق كل طبقة.

**الحالة:** `PLANNED_VERIFICATION_MATRIX`.

## ملحق: التمدد المشروط بالثقة

يُسجل الوصول إلى مليارات الأنوية هدفاً بعيد المدى ناتجاً عن التمدد المستمر، ولا يُعد رقماً حالياً. ويكون التمدد مشروطاً بقبول المستخدمين والمؤسسات وبقاء شروط السلامة والمنفعة والشفافية والامتثال الدستوري مستوفاة.

| ادعاء التمدد | نوع الدليل | الحكم |
|---|---|---|
| يمكن أن تنمو UORI عبر أنوية جديدة عند تحقق شروط القبول | سجل عضوية وإصدارات واختبارات ضمن نطاق | `CONDITIONAL_GOAL` |
| الثقة التشغيلية يمكن قياسها بمؤشرات الاستخدام والرضا والحوادث | سجلات مستقلة ومعايير معلنة | `PLANNED_METRIC` |
| تؤدي الشعبية وحدها إلى سلامة الخوارزمية | لا تكفي تقييمات المستخدمين لإثبات ذلك | `REJECTED_AS_INFERENCE` |
| تعمل مليارات الأنوية حالياً | إحصاء عالمي قابل للتدقيق غير متوفر | `ABSTAIN` |
| التمدد لا يتجاوز الدستور | سجلات قبول وإلغاء واختبارات دورية | `CONSTITUTIONAL_REQUIREMENT` |

لا يجوز إدراج نواة جديدة بسبب الثقة الاجتماعية وحدها إذا غاب دليل الهوية أو السلامة أو توافق الموارد. ولا يجوز استخدام رقم مستهدف مستقبلي في وصف الحالة التشغيلية الحالية.
