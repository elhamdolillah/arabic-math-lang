# التوازي والاتساق والتعافي في خلايا UORI

## 1. الغرض

يحدد هذا المستند قواعد تشغيل الخلايا اللامركزية عندما تنفذ أنوية متعددة مهمة واحدة بالتوازي، مع منع الخلط بين التوازي وبين صحة النتيجة. التوازي يصف طريقة توزيع العمل، أما صحة النتيجة فتحتاج إلى عقد تحقق وأدلة مستقلة.

## 2. عقد المهمة الموزعة

قبل توزيع أي مهمة، تنشئ الخلية عقداً يحدد معرف المهمة، الإصدار، المدخلات وبصماتها، المخرجات المطلوبة، الموارد المسموح بها، المهلة، سياسة التكرار، معيار الاتساق، وسلوك الفشل. لا تُسند مهمة إلى نواة لا تحمل نطاق قدرة مناسباً أو لا تملك عضوية صالحة.

| العنصر | القاعدة |
|---|---|
| تقسيم العمل | إلى وحدات محددة قابلة للتعريف وإعادة التنفيذ |
| الإسناد | إلى نواة مقبولة ضمن نطاقها |
| التكرار | يستخدم عند الحاجة للتحقق أو تحمل الفشل |
| النتيجة | ترتبط بالمدخلات والإصدار والبصمات |
| التعارض | يعالج بقاعدة معلنة أو يؤدي إلى الامتناع |
| المهلة | تنهي العمل غير المكتمل دون منح صلاحية إضافية |

## 3. نماذج الاتساق

تختار الخلية واحداً من ثلاثة نماذج: اتساق حتمي عندما تكون العملية قابلة للتكرار ومدخلاتها مكتملة؛ اتساق فتري عندما تكون النتيجة ضمن حدود مضمونة؛ أو اتساق احتمالي عندما يكون التوزيع أو التقدير معايراً ببيانات كافية. أما مخرجات النماذج التوليدية فتظل فرضيات أو شروحاً ولا تتحول إلى قرار تشغيلي وحدها.

إذا اختلفت النوى، تسجل الخلية كل نتيجة ولا تنتخب الأكثر شيوعاً تلقائياً. تجري المقارنة بحسب العقد: تطابقاً حتمياً، أو تقاطعاً فترية، أو اختباراً إحصائياً معلناً. وإذا لم تنطبق القاعدة، يكون القرار `ABSTAIN` مع حفظ الأدلة.

## 4. سجل الأحداث

يحمل كل حدث معرفاً متسلسلاً، ومعرف النواة، ومعرف الخلية، ووقتاً موحداً، ونوع الحدث، وبصمة الحمولة، والنتيجة، وسبب القرار. تربط الخلية الأحداث بسلسلة SHA-256 حتى يمكن كشف الحذف أو التعديل أو إعادة الترتيب. لا تُسجل الأسرار الخام؛ وتستخدم مراجع أو بصمات عندما تكون البيانات حساسة.

## 5. الانقطاع والتعافي

عند فقد القناة، تنتقل النواة إلى وضع محلي محدود. تكمل الأعمال التي لا تحتاج طرفاً خارجياً، وتوقف العمليات التي تتطلب عضوية أو تفويضاً أو مورداً بعيداً. تحفظ نقطة الاستئناف وبصمة الحالة، ثم تطلب عند عودة الاتصال مصالحةً لا استئنافاً أعمى.

تتحقق المصالحة من الإصدار السابق، وبصمة الحالة، وتسلسل الأحداث، وحالة الإلغاء. فإذا تطابقت السلسلة، يستأنف العمل من نقطة معروفة. وإذا وقع تعارض، تنشئ الخلية فرعاً معزولاً أو تعيد المهمة. وإذا تعذر إثبات أي مسار، تمتنع عن الدمج.

## 6. حدود الضرر

لا يمنح التوازي للخلايا قدرة على تجاوز العزل أو تغيير صلاحيات نواة أخرى. تحدد كل مهمة ميزانية للوقت والذاكرة والرسائل والطاقة والعمليات العتادية. وتوقف الخلية العمل عند تجاوز الميزانية أو ظهور سلوك غير متوقع، ثم تسجل الحادثة وتبدأ مسار الإلغاء أو الحجر.

## 7. الحالة

| الادعاء | الحكم |
|---|---|
| يمكن تعريف توزيع أعمال بين أنوية UORI | `DESIGN_DEFINED` |
| يمكن تسجيل نتائج متوازية بسلسلة قابلة للتدقيق | `PLANNED` حتى تنفيذ واختبار |
| يضمن النموذج اتساقاً عالمياً فورياً | `ABSTAIN`؛ يعتمد على الشبكة والعقد والتنفيذ |
| يمكن للنواة التعافي بعد الانقطاع | `PLANNED` حتى اختبار قابل لإعادة الإنتاج |
| التوازي يثبت سلامة النتائج | `REJECTED_AS_INFERENCE`؛ يلزم دليل صحة مستقل |

**الخلاصة:** التوازي وسيلة لبناء UORI UNIVERS، وليس دليلاً ذاتياً على السلامة أو الصحة أو الاتساق العالمي. كل خلية ملزمة بالعقد، وسجل الأحداث، وحدود الموارد، وسياسة الامتناع.
