# أدلة سلامة وكفاءة خوارزميات UORI

**الحالة:** `EVIDENCE_POLICY_SPECIFICATION` — تحدد هذه الوثيقة شروط الإثبات ولا تدعي أن جميع خوارزميات UORI اجتازت هذه الشروط.

## المبدأ

لا تُعرّف سلامة الخوارزمية بغياب حادثة في تجربة قصيرة، ولا تُعرّف الكفاءة بعبارة عامة مثل «الأسرع». يجب ربط كل حكم بخوارزمية وإصدار وبيئة ومدخلات ومقياس وحدود. ويكون الادعاء دائماً من الشكل: **هذه الخوارزمية آمنة أو كفؤة ضمن النطاق المحدد وبقدر الأدلة المسجلة**.

## طبقات دليل السلامة

| الطبقة | ما الذي تختبره | الحد الأدنى للدليل |
|---|---|---|
| سلامة العقد | مطابقة المدخلات والمخرجات والأنواع | حالات صحيحة وحالات رفض موثقة |
| سلامة الموارد | عدم تجاوز الزمن والذاكرة والتخزين والصلاحيات | قياسات حدودية وسجل إيقاف |
| سلامة العزل | منع الوصول خارج النطاق | محاولات وصول مرفوضة وسجلها |
| سلامة الاتصال | عدم إرسال غير مصرح أو كشف أسرار | بيئة شبكة معزولة وسجل رسائل |
| سلامة الأثر | عدم إحداث تغيير غير معلن في العتاد أو البيئة | مقارنة قبل/بعد وآلية إلغاء |
| السلامة الرسمية | إثبات خاصية رياضية أو منطقية محددة | ملف برهان ناجح ومستقل النطاق |

## طبقات دليل الكفاءة

تسجل الكفاءة باستخدام مدخلات ثابتة، وأداة ونسخة ثابتة، وبيئة معلومة، وعدد تكرارات معلن، ومقياس محدد مثل الزمن أو الذاكرة أو الطاقة أو معدل النقل. ولا تقارن نتيجتان إلا إذا تساوت شروط القياس أو سُجل سبب الاختلاف. وتكون النتيجة «أقصى كفاءة مثبتة» داخل مجموعة الاختبارات فقط، لا أفضلية مطلقة على كل خوارزمية أو عتاد.

## اختيار المسار الدستوري

يستخدم المسار الحتمي عندما يكون مجال المدخلات مستوفياً وحد الخطأ مقبولاً. ويستخدم الحساب الفتري عندما تكون الحدود مضمونة. ويستخدم المسار الاحتمالي فقط عندما تتوفر بيانات كافية وتوزيع معلوم ومعايرة قابلة للفحص. ويمكن للذكاء الاصطناعي التوليدي اقتراح حالات اختبار أو تفسير نتائج، لكنه لا يمثل دليلاً بذاته.

## سجل الدليل الإلزامي

| الحقل | الغرض |
|---|---|
| معرف الخوارزمية والإصدار والتاريخ | تثبيت هوية المادة المختبرة |
| بصمة SHA-256 للمصدر والتبعيات | كشف التغير |
| الجهاز والمعمارية ونظام التشغيل أو المحاكي | تحديد البيئة |
| المدخلات ومجموعة الاختبار | تحديد مجال الادعاء |
| المقياس والنتيجة وحدود الخطأ | تعريف الكفاءة أو الدقة |
| سجل الأثر والموارد | تقييم السلامة التشغيلية |
| رمز الخروج والمخرجات الخام | إعادة الإنتاج |
| إصدار السياسة والأدوات | تحديد شروط القرار |
| الحكم وسببه | فصل `PASS` عن `BLOCKED` و`ABSTAIN` |

## قواعد الامتناع

تُرجع النواة `ABSTAIN` إذا لم تكفِ العينة أو لم تُعرف البيئة أو تعذر التحقق من البصمة أو كان مقياس الكفاءة غير معرف. وتُرجع `BLOCKED` إذا منع نقص الأداة أو الصلاحية أو العتاد تنفيذ الاختبار. ولا يجوز استعمال تقييم المستخدمين أو ادعاء المصدر المفتوح لتعويض دليل السلامة أو البرهان.
