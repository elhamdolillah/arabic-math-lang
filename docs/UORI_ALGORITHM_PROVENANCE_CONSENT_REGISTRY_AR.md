# سجل الأصل والموافقة للخوارزميات المدمجة في UORI

## 1. الغرض

يسجل هذا العقد أصل كل خوارزمية مدمجة في UORI، وصاحب الحقوق أو الممثل المخول، وبيان الموافقة، ونوع الترخيص، والإصدار، والبصمة، ونطاق الإتاحة، وتصنيف المعطيات المصاحبة. لا تُعد الخوارزمية جزءاً من الإصدار العام قبل اكتمال السجل والتحقق من الاتساق بين الكود والمواصفة والبصمة.

## 2. السجل الأدنى

| الحقل | الوصف |
|---|---|
| `algorithm_id` | معرف ثابت للخوارزمية |
| `release_id` | معرف الإصدار المحدد |
| `author_or_rights_holder` | المطور أو صاحب الحق أو الممثل الموثق |
| `consent_record` | سجل الموافقة وتاريخها وطريقة إثباتها |
| `license_id` | الترخيص الذي يحدد الإتاحة والاستعمال والتعديل |
| `source_uri` | مصدر الكود أو المواصفة |
| `content_sha256` | بصمة المحتوى المقبول |
| `data_classification` | عام، مقيد، شخصي، أو سري |
| `scope` | نطاق التشغيل والعتاد والاستخدام |
| `status` | مقترح، معزول، مقبول، موقوف، أو ملغى |

## 3. قواعد المطابقة

لا تكفي الموافقة إذا كانت تخص اسماً عاماً بلا إصدار أو بصمة محددة. ويجب أن تطابق البصمة النسخة التي اختُبرت، وأن يطابق الترخيص نطاق الإتاحة المعلن، وأن تكون المعطيات المرفقة مصنفة قبل النشر. أي تعارض بين السجل والمصدر أو الإصدار يؤدي إلى `ABSTAIN` أو `QUARANTINED` بحسب مستوى الخطر.

## 4. سجل التغييرات

كل تعديل ينشئ إصداراً جديداً أو حدثاً موثقاً، ولا يستبدل التاريخ بصمت. تسجل UORI تاريخ الموافقة، وتاريخ القبول، وتاريخ التحديث، وتاريخ التعليق أو السحب، مع بصمات السجلات ذات الصلة. وإذا تغير صاحب الحق أو الترخيص، تتوقف الإتاحة الجديدة حتى إعادة التحقق.

## 5. حدود الملكية البشرية العامة

يُعبّر السجل عن إتاحة الخوارزمية للمنفعة البشرية العامة وفق ترخيص صريح، ولا يفترض انتقال الملكية القانونية أو إسقاط الحقوق المعنوية أو الحقوق المقيدة دون نص قانوني واضح من صاحب الحق. أما القواعد الرياضية والعلمية المنشورة للعموم بموافقة أصحابها فتسجل كمصادر عامة ضمن حدود حقوق نشرها وصياغتها الأصلية.

**الحالة:** `PLANNED_REGISTRY_SCHEMA`.
