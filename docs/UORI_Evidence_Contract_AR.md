# عقد النتيجة الموثقة في UORI

## الغرض

يحدد هذا العقد الحد الأدنى الذي يجب أن يرافق كل نتيجة تنتجها دالة عددية أو خوارزمية تحليلية في UORI. العقد لا يثبت صحة العالم الخارجي، لكنه يمنع فقدان السياق، ويفصل صحة الحساب عن جودة القياس وقوة الدليل.

> النتيجة الموثقة ليست قيمة فقط؛ بل قيمة مع مصدرها، وتحويلاتها، وبرهانها، وحدود استعمالها.

## المكونات الإلزامية

| الحقل | الوظيفة | مثال |
|---|---|---|
| `معرّف_النتيجة` | هوية ثابتة للنتيجة | `R-2026-0001` |
| `القيمة` | القيمة المخرجة قبل العرض وبعده عند الحاجة | `7.42` |
| `الوحدة` | الوحدة والدلالة الفيزيائية | `mmol/L` |
| `الدالة` | اسم الدالة العربية وإصدارها | `وتر@1` |
| `المعادلة` | الصيغة المصدرية | `جذر(س² + ص²)` |
| `المجال` | مجال المدخلات المقبول | `س،ص ∈ Q32.32` |
| `التمثيل` | Q-format المستخدم | `Q32.32 داخلياً Q64.64` |
| `التقريب` | سياسة التقريب والحد | `أقرب، حد الخطأ 16` |
| `حالة_الفيض` | نتيجة فحص الفيض | `سليم` أو `مرفوض` |
| `صحة_الحساب` | حالة التحقق العددي والصوري | `متحقق عددياً، نموذج Coq ناجح` |
| `مصدر_المدخل` | مرجع البيانات الخام | معرّف provenance |
| `جودة_القياس` | حالة المصدر المخبري أو التجريبي | `موثقة` أو `ناقصة` |
| `قوة_الدليل` | قوة الدليل الخارجي | `A` إلى `E` داخلياً |
| `عدم_اليقين` | الفاصل أو أسباب عدم اليقين | قيمة ونموذج وافتراضات |
| `الاستخدام_المسموح` | ما يمكن فعله بالنتيجة | `بحث، فرز، دعم قرار` |
| `الاستخدام_الممنوع` | ما لا يجوز فعله آلياً | `تشخيص، علاج، رفض مريض` |
| `إصدار_الخوارزمية` | نسخة المصدر والتنفيذ | commit أو digest |
| `بصمة_النتيجة` | كشف التغيير | SHA-256 |

## قواعد الانتقال بين الحالات

لا تنتقل النتيجة إلى حالة «قابلة للاستعمال» إلا إذا نجح الحساب، وسلامة التمثيل، وفحص اكتمال المصدر المطلوب لذلك النوع من الاستخدام. فشل Coq أو فشل اختبار العتاد يمنع رفع حالة الحساب، لكنه لا يبرر حذف المدخلات أو إخفاء النتيجة.

إذا كانت القيمة صحيحة حسابياً لكن مصدرها ناقص، تكون الحالة: **حساب صحيح على مدخل غير موثق**. وإذا كان المصدر موثقاً لكن الدليل السريري ضعيفاً، تكون الحالة: **بيانات موثقة ذات استخدام بحثي محدود**. لا يجوز اختزال الحالتين في وسم «صحيح» فقط.

## سياسة provenance

يجب أن تكون كل عملية تحويل سجلاً غير قابل للتعديل منطقياً، يحتوي على المعرّف السابق، والمُحوِّل، وإصدار القاعدة، والوقت، والمدخل والمخرج، وسبب العملية. لا تُحذف القيمة الخام عند التنظيف؛ بل تُحفظ مع إشارة إلى النسخة المنقحة وسبب التغيير.

## بوابة CI

تتحقق بوابة CI من أربعة مستويات منفصلة:

1. صحة المخطط والحقول الإلزامية.
2. تطابق بصمة التنفيذ وإصدار الخوارزمية.
3. نجاح oracle والاختبارات العددية وفحوص الفيض.
4. نجاح Coq، مع عرض الافتراضات وعدم تحويل نجاح النموذج إلى ادعاء لصحة العالم الخارجي.

## حدود الإصدار الأول

الإصدار الأول من العقد غير تشخيصي. يسمح بالتحليل البحثي، وفحص جودة البيانات، والتحويلات العددية، وتتبع المصدر، وإصدار التنبيهات. ولا يسمح بالتشخيص الآلي، أو وصف العلاج، أو قبول أو رفض مريض، أو إخفاء نتيجة شاذة دون مراجعة بشرية.
