# الفصل التاسع: السمات (Traits)

## 9.1 تعريف السمات

```arabic
سمة قابلة_للطباعة(ن) : ﴿ اطبع_ذاتي : ن → نص ﴾
سمة مساحة(ن) : ﴿ احسب : ن → عدد ﴾
```

## 9.2 تطبيق السمات

```arabic
تطبيق قابلة_للطباعة على نقطة : ﴿ اطبع_ذاتي(ن) ≔ "نقطة" ﴾
```

يُولَّد closure داخلي: `__trait__{سمة}__{نوع}__{دالة}`.

## 9.3 الإرسال الديناميكي

عند استدعاء دالة سمة، يرسل المحرك إلى impl النوع المكتشف:

- نوع الوسيط من استدعاء باني: يُحدد من `_type_registry`.
- داخل دوال عامة (`λس. احصل(س)·2`): يُختار impl الوحيد المبني في التجميع الحالي (مرجع P9).

## 9.4 السمات المتعددة

نوع واحد يحمل عدة سمات، وسمة واحدة تُطبَّق على عدة أنواع (multi-impl).

## 9.5 المقارنة مع Rust/Haskell

| المفهوم | Rust | Haskell | لغتنا |
|---------|------|---------|-------|
| trait/typeclass | trait | typeclass | سمة |
| impl/instance | impl | instance | تطبيق |
| dispatch | vtable/static | dictionary | closure lookup تجميعي |
| generics | impl Trait / T | معيقات | إرسال ديناميكي |
