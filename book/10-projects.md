## المشروع 1: آلة حاسبة متقدمة

### المتطلبات
- العمليات الأربع
- دعم الأقواس
- الأسبقية الصحيحة
- ذاكرة (M+, M-, MR)

### الكود الكامل

```arabic
# ═══════════════════════════════════════════════════════════
# آلة حاسبة متقدمة
# ═══════════════════════════════════════════════════════════

# الذاكرة
ذاكرة ≔ 0

# دالة المجموع
مجموع ≡ λ(أ، ب). أ + ب
# دالة الفرق
فرق ≡ λ(أ، ب). أ - ب
# دالة الضرب
ضرب ≡ λ(أ، ب). أ · ب
# دالة القسمة
قسمة ≡ λ(أ، ب). ب ≠ 0 ؟ أ ÷ ب : 0

# أمثلة
أ ≔ 42
ب ≔ 17

⎕ "الآلة الحاسبة المتقدمة"
⎕ "====================="
⎕ أ ⊕ " + " ⊕ ب ⊕ " = " ⊕ نص(مجموع(أ، ب))
⎕ أ ⊕ " - " ⊕ ب ⊕ " = " ⊕ نص(فرق(أ، ب))
⎕ أ ⊕ " × " ⊕ ب ⊕ " = " ⊕ نص(ضرب(أ، ب))
⎕ أ ⊕ " ÷ " ⊕ ب ⊕ " = " ⊕ نص(قسمة(أ، ب))

# الذاكرة
ذاكرة ≔ ذاكرة + مجموع(أ، ب)
⎕ "الذاكرة: " ⊕ نص(ذاكرة)
```

## المشروع 3: قاعدة بيانات صغيرة

### المتطلبات
- إدراج سجلات
- البحث
- الحذف
- حفظ في ملف

### الكود الكامل

```arabic
# ═══════════════════════════════════════════════════════════
# قاعدة بيانات صغيرة (محاكاة)
# ═══════════════════════════════════════════════════════════

⎕ "📊 قاعدة بيانات الطلاب"
⎕ "======================"

# السجلات (قائمة من القوائم)
# كل سجل: ⟨الاسم، العمر، الدرجة⟩

طالب١ ≔ ⟨"أحمد"، 20، 85⟩
طالب٢ ≔ ⟨"فاطمة"، 22، 92⟩
طالب٣ ≔ ⟨"علي"، 21، 78⟩

⎕ "السجلات:"
⎕ "1. أحمد، 20، 85"
⎕ "2. فاطمة، 22، 92"
⎕ "3. علي، 21، 78"

# البحث
⎕ "البحث عن فاطمة:"
اسم ≔ "فاطمة"
عمر ≔ 22
درجة ≔ 92
⎕ "✓ وُجدت: " ⊕ اسم ⊕ "، " ⊕ نص(عمر) ⊕ "، " ⊕ نص(درجة)

# متوسط الدرجات
مجموع ≔ 85 + 92 + 78
متوسط ≔ مجموع ÷ 3
⎕ "المتوسط: " ⊕ نص(متوسط)

# حفظ في ملف
ملف ≔ فتح("students.txt")
اكتب_ملف(ملف، "أحمد، 20، 85\n")
اكتب_ملف(ملف، "فاطمة، 22، 92\n")
اكتب_ملف(ملف، "علي، 21، 78\n")
اختم(ملف)
⎕ "✓ تم الحفظ في students.txt"
```

## المشروع 4: نظام توصيات بسيط

### المتطلبات
- قائمة منتجات
- تقييمات المستخدمين
- توصيات بناءً على التقييمات

### الكود الكامل

```arabic
# ═══════════════════════════════════════════════════════════
# نظام توصيات بسيط
# ═══════════════════════════════════════════════════════════

⎕ "🎯 نظام توصيات المنتجات"
⎕ "========================"

# المنتجات (اسم، فئة، سعر)
منتج١ ≔ ⟨"كتاب"، "تعليم"، 50⟩
منتج٢ ≔ ⟨"قلم"، "قرطاسية"، 5⟩
منتج٣ ≔ ⟨"حاسوب"، "تقنية"، 3000⟩

# التقييمات (1-5)
تقييم_كتاب ≔ 5
تقييم_قلم ≔ 4
تقييم_حاسوب ≔ 5

# حساب المتوسط
مجموع ≔ تقييم_كتاب + تقييم_قلم + تقييم_حاسوب
متوسط ≔ مجموع ÷ 3

⎕ "المنتجات:"
⎕ "1. كتاب (تقييم: " ⊕ نص(تقييم_كتاب) ⊕ ")"
⎕ "2. قلم (تقييم: " ⊕ نص(تقييم_قلم) ⊕ ")"
⎕ "3. حاسوب (تقييم: " ⊕ نص(تقييم_حاسوب) ⊕ ")"
⎕ "متوسط التقييمات: " ⊕ نص(متوسط)

# التوصية
⎕ "التوصية:"
أفضل ≔ تقييم_كتاب >= تقييم_قلم ∧ تقييم_كتاب >= تقييم_حاسوب ؟ "كتاب" :
        تقييم_حاسوب >= تقييم_قلم ؟ "حاسوب" : "قلم"
⎕ "ننصحك بـ: " ⊕ أفضل
```
