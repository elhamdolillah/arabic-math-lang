# الفصل الأول: مقدمة في اللغة الرياضية العربية

## 1.1 لماذا لغة عربية؟

لغات البرمجة السائدة كلها مكتوبة بحروف لاتينية، مما يجعل علوم الحاسب حاجزًا أمام المتحدثين بالعربية.
هذه اللغة تُثبت أن العربية قادرة على التعبير عن أعقد مفاهيم البرمجة: الملكية الخطية، الأنواع الجبرية، السمات، والتوازي الفعلي.

## 1.2 الدستور v8.0

ثمانية مبادئ تُحكم التصميم: الإحكام، التيسير، العدل، الأمانة، البيان، الحفظ، التفكر، والشمولية.
راجع `docs/CONSTITUTION.md`.

## 1.3 الرموز العشرين

```
≔  ≡  ⎕  λ  μ  ∀  ∈  ⟨⟩  ﴿﴾  ⊕  ·  +  -  ·  :  ؟  ⋄  ⇒  ⊸  ⊙
```

| الرمز | المعنى |
|-------|--------|
| ≔ | إسناد قيمة |
| ≡ | تعريف دالة |
| ⎕ | طباعة |
| λ | إغلاق (closure) |
| μ | حلقة while |
| ∀ | تكرار على قائمة |
| ⟨ ⟩ | قائمة |
| ﴿ ﴾ | كتلة |
| ⊕ | دمج النصوص |
| ⊸ | ملكية خطية |

## 1.4 أول برنامج: مرحبا بالعالم

```arabic
⎕ "مرحبا بالعالم"
```

يُجمَّع إلى ثنائي ELF مستقل بحجم ~11KB، بدون libc.

## 1.5 هيكل المُجمّع

```
مصدر عربي → حلل_رموز (Lexer) → حلل_برنامج (Parser)
          → استنتاج_نوع → compile_program (CodeGen)
          → NASM → ld → ELF
```

> **«وَقُل رَّبِّ زِدْنِي عِلْمًا»**
