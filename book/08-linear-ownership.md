# الفصل 8: الملكية الخطية (Linear Ownership)

## مقدمة

الملكية الخطية هي **أهم ميزة أمان** في لغتنا. مستوحاة من:
- Linear Logic (Girard, 1987)
- Ownership Types (Clarke, 1998)
- نظام Rust (2010)

```text
القاعدة الذهبية:
"كل مورد له مالك واحد فقط في أي لحظة"
```

---

## المبادئ الثلاثة

### 1. كل قيمة لها مالك

```arabic
س ≔ 42        # س يملك 42
ص ≔ "مرحبا"   # ص يملك النص
```

### 2. مالك واحد فقط

```arabic
س ≔ ⟨1, 2, 3⟩  # س يملك القائمة
ص ≔ س          # ❌ خطأ! لا يمكن النسخ
ص ≔ س ⊸         # ✅ نقل الملكية من س إلى ص
```

### 3. التحرير عند الخروج من النطاق

```arabic
دالة ≡ λ(). ﴿
    ق ≔ ⟨1, 2, 3⟩
    ⎕ رأس(ق)
﴾
# ق تُحرر تلقائياً عند انتهاء الدالة
```

---

## أنواع القيم

### القيم القابلة للنسخ (Copyable)

```arabic
# الأعداد: تُنسخ تلقائياً
س ≔ 42
ص ≔ س           # ✅ نسخ
⎕ س              # 42 ✅ (لا يزال صالحاً)
⎕ ص              # 42 ✅
```

### القيم الخطية (Linear)

```arabic
# القوائم: تُنقل فقط
ق١ ≔ ⟨1, 2, 3⟩
ق٢ ≔ ق١          # ❌ خطأ! استخدم ⊸
ق٢ ≔ ق١ ⊸        # ✅ نقل
⎕ ق٢             # ⟨1, 2, 3⟩ ✅
⎕ ق١             # ❌ خطأ: ق١ منقول
```

### جدول الأنواع

| النوع | قابل للنسخ؟ | مثال |
|-------|-------------|------|
| عدد | ✅ نعم | `42` |
| منطقي | ✅ نعم | `1`, `0` |
| نص | ❌ لا | `"مرحبا"` |
| قائمة | ❌ لا | `⟨1, 2, 3⟩` |
| ملف | ❌ لا | `فتح("f.txt")` |
| مقبض | ❌ لا | `عروة()` |

## عملية النقل (⊸)

### الصياغة

```arabic
هدف ≔ مصدر ⊸
```

### ما يحدث في الكواليس

```text
قبل:
┌─────────┐        ┌───────────────┐
│   س     │───────▶│  ⟨1, 2, 3⟩    │
│ (مالك)  │        │  في arena      │
└─────────┘        └───────────────┘

بعد: ص ≔ س ⊸
┌─────────┐        
│   س     │ (لم يعد صالحاً)
│  ✗      │        
└─────────┘        
                   
┌─────────┐        ┌───────────────┐
│   ص     │───────▶│  ⟨1, 2, 3⟩    │
│ (مالك)  │        │  في arena      │
└─────────┘        └───────────────┘
```

### التحقق في وقت التجميع

```python
def check_move(source_var, env):
    if source_var in env.moved:
        raise Exception(
            f"❌ خطأ ملكية: المتغير '{source_var}' منقول مسبقاً\n"
            f"   الموقع: السطر {env.last_use[source_var]}\n"
            f"   الدستور: ﴿أدوا الأمانات إلى أهلها﴾"
        )
    env.moved.add(source_var)
```

## أمثلة عملية

### مثال 1: تمرير للقائمة

```arabic
# دالة تأخذ قائمة
طول_قائمة ≡ λق. أحص(ق)

ق ≔ ⟨1, 2, 3, 4, 5⟩
ن ≔ طول_قائمة(ق ⊸)   # نقل الملكية للدالة
⎕ ن                      # 5 ✅
# ⎕ أحص(ق)             # ❌ ق منقولة
```

### مثال 2: إرجاع القائمة

```arabic
# دالة تُرجع قائمة
أنشئ_قائمة ≡ λ(). ⟨1, 2, 3⟩

ق ≔ أنشئ_قائمة()
⎕ أحص(ق)               # 3 ✅
```

### مثال 3: سلاسل العمليات

```arabic
# دالة تضاعف عناصر قائمة
ضاعف ≡ λق. ∀ ع ∈ ق : ⟨ ع · 2 ⟩

ق ≔ ⟨1, 2, 3⟩
ص ≔ ضاعف(ق ⊸)
⎕ ص                     # ⟨2, 4, 6⟩
```

## القواعد الرسمية

### قاعدة النقل

```text
Γ ⊢ e : T     x ∈ Γ     T linear
───────────────────────────── [Move]
Γ - {x} ⊢ x ⊸ e : T
```

### قاعدة الاستهلاك

```text
Γ ⊢ e : T     x ∉ Γ     T linear
───────────────────────────── [No-Use]
Γ ⊬ x
```

### قاعدة النسخ (للأنواع غير الخطية)

```text
Γ ⊢ e : T     T copyable
────────────────────── [Copy]
Γ ⊢ e : T    (Γ يبقى كما هو)
```

## البرهان على الأمان

### النظرية: لا use-after-free

**البرهان:**
1. كل قيمة خطية لها مالك واحد فقط
2. عند النقل، يفقد المالك الأصلي الحق
3. المُجمّع يرفض الوصول للمالك القديم
4. ∴ لا يمكن استخدام قيمة بعد نقلها ∎

### النظرية: لا double-free

**البرهان:**
1. كل قيمة لها مالك واحد
2. التحرير يحدث عند انتهاء نطاق المالك
3. لا يمكن أن ينتهي نطاقان لنفس القيمة
4. ∴ لا تحرير مزدوج ∎

### النظرية: لا تسريب ذاكرة

**البرهان:**
1. كل قيمة مملوكة لمتغير
2. المتغيرات تُحرر عند خروجها من النطاق
3. Arena يُحرر بالكامل عند انتهاء البرنامج
4. ∴ لا تسريب ∎

## المقارنة مع Rust

| الميزة | لغتنا | Rust |
|--------|-------|------|
| Linear types | ✅ نقية | ⚠️ Affine |
| Borrow checker | ❌ لا | ✅ نعم |
| Lifetimes | ❌ لا | ✅ نعم |
| Reference counting | ❌ لا | ✅ نعم (Rc) |
| التعقيد | بسيط | معقد |
| القوة التعبيرية | متوسطة | عالية |

### لماذا اخترنا Linear بدلاً من Affine؟

```text
Linear (لغتنا): كل مورد يُستخدم مرة واحدة بالضبط
Affine (Rust): كل مورد يُستخدم مرة واحدة على الأكثر

Linear أبسط وأسهل للفهم، لكنه أقل مرونة.
```

## أنماط شائعة

### نمط 1: Builder

```arabic
# بناء كائن خطوة بخطوة
أنشئ ≔ λ(). ⟨⟩
أضف ≔ λ(ق، ع). ق ⊕ ⟨ع⟩

ق ≔ أنشئ()
ق ≔ أضف(ق ⊸، 1)
ق ≔ أضف(ق ⊸، 2)
ق ≔ أضف(ق ⊸، 3)
⎕ ق    # ⟨1, 2, 3⟩
```

### نمط 2: Pipeline

```arabic
# معالجة سلسلة
عالج ≔ λنص. نص ⊕ "!"
ن ≔ "مرحبا"
ن ≔ عالج(ن ⊸)
ن ≔ عالج(ن ⊸)
⎕ ن    # "مرحبا!!"
```

### نمط 3: State Machine

```arabic
# آلة حالات
حالة ≔ "بداية"
حالة ≔ "تشغيل" ⊸    # نقل
حالة ≔ "نهاية" ⊸
```

## الأخطاء الشائعة

### خطأ 1: استخدام بعد النقل

```arabic
ق ≔ ⟨1, 2, 3⟩
ص ≔ ق ⊸
⎕ ق    # ❌ خطأ: ق منقولة
```

**الرسالة:**
```text
❌ خطأ ملكية في السطر 3:
   المتغير 'ق' منقول مسبقاً في السطر 2
   
   ﴿أدوا الأمانات إلى أهلها﴾
   Hint: استخدم نسخة أو أعد الإنشاء
```

### خطأ 2: النقل المتكرر

```arabic
ق ≔ ⟨1, 2, 3⟩
دالة١(ق ⊸)
دالة٢(ق ⊸)    # ❌ خطأ: ق منقولة مرتين
```

### خطأ 3: النسخ غير المصرح به

```arabic
ق ≔ ⟨1, 2, 3⟩
ص ≔ ق    # ❌ خطأ: القوائم لا تُنسخ
```

## تطبيقات متقدمة

### 1. الموارد الخارجية

```arabic
# الملفات خطية
ملف ≔ فتح("test.txt")
اكتب_ملف(ملف ⊸، "محتوى")
# ❌ لا يمكن استخدام 'ملف' بعد الآن
# ✅ يجب فتح ملف جديد
```

### 2. المقابض الشبكية

```arabic
# Sockets خطية
ع ≔ عروة()
اتصل(ع ⊸، "example.com"، 80)
# ✅ لا تسريب sockets
```

### 3. الـ Channels (في التوازي)

```arabic
# القنوات خطية
ق ≔ قناة()
أرسل(ق ⊸، "رسالة")
# ✅ لا double-send
```

## الخلاصة

الملكية الخطية هي **قلب أمان اللغة**:
- تضمن سلامة الذاكرة
- تمنع التسريبات
- تبسط التفكير
- تجعل الأخطاء واضحة في وقت التجميع

بهذا نكون قد أكملنا **الجزء الثاني من الكتاب**. في الجزء الثالث، سندرس **المكتبة القياسية** و**المشاريع التطبيقية**.
