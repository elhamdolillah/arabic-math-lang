# الفصل الرابع: الملكية الخطية (⊸)

## 4.1 مبدأ الأمانة

```
∀ مورد ر، ∀ لحظة ز: ∃! مالك م: يملك(م، ر، ز)
```

كل قيمة heap لها مالك واحد في كل لحظة — لا مشاركة، لا نسخ ضمني.

## 4.2 نقل الملكية

المرور للدوال ينقل الملكية (`⊸`):

```arabic
د ≡ λس ⊸. س    ← س تُستهلك
```

## 4.3 رفض use-after-move

المُجمّع يرفض استخدام متغير بعد نقل ملكيته — يُكتشف في وقت التجميع (مبدأ التفكر).

## 4.4 رفض double-move

نقل المورد مرتين خطأ تجميعي.

## 4.5 المقارنة مع Rust

| المفهوم | Rust | لغتنا |
|---------|------|-------|
| Ownership | move semantics | `⊸` + فحص تجميعي |
| Borrowing | `&`, `&mut` | غير مطلوب — Arena بسيط |
| Drop | traits | لا freeing فردي — Arena كُلي |

> كل مورد له مالك واحد — المبدأ الرابع
