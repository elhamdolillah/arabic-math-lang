# الفصل الثاني: المحلل المعجمي (Lexer)

## 2.1 تتبع السطر والعمود

كل رمز يحمل إحداثيات (سطر، عمود) لتوليد رسائل أخطاء دقيقة.

## 2.2 الرموز العربية

يعرّف Lexer الرموز العربية (≔، ≡، ⎕، λ، μ، ∀، ∈، ﴿، ﴾، ⋄، ⇒، ⊸، ⊕، ⊙) مع رموز Unicode الزخرفية البديلة.

## 2.3 الحركات العربية (التشكيل)

الفاصلة العربية `،` تُميَّز عن فواصل الأنواع، والرموز المتشابهة تُحلّ بسياق محدد لا لبس فيه (مبدأ الإحكام).

## 2.4 الأسماء البديلة

`أسماء_بديلة` تسمح بكتابة `تطبيق` أو `سمة` بالعربية الفصحى مع قبول صيغ متقاربة، بما يحافظ على التيسير دون التباس.

## 2.5 رسائل الخطأ

```
خطأ في السطر 3، العمود 12: رمز غير معروف: 'x'
```

> كل رمز له معنى واحد — المبدأ الأول
