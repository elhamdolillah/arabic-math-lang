# الفصل 2: نظرة عامة على المُجمّعات

## ما هو المُجمّع؟

المُجمّع (Compiler) هو برنامج يحوّل كوداً مكتوباً بلغة عالية المستوى إلى كود بلغة منخفضة المستوى يمكن للحاسوب تنفيذه.

```text
الكود المصدري (Source Code)
     ↓
   [المُجمّع]
     ↓
الكود الهدف (Target Code)
```

---

## أنواع المُجمّعات

### 1. المُجمّعات الكاملة (AOT)

```text
الكود → المُجمّع → ملف تنفيذي → تشغيل
```

**أمثلة:**
- C, C++, Rust, Go
- **لغتنا العربية** ✅

### 2. المُجمّعات اللحظية (JIT)

```text
الكود → مترجم → كود وسيط → مُجمّع لحظي → تشغيل
```

**أمثلة:** Java, JavaScript

### 3. المترجمات (Interpreters)

```text
الكود → مترجم → تنفيذ مباشر
```

**أمثلة:** Python, Ruby

---

## مراحل التجميع الأربع

### المخطط العام

```text
┌─────────────────────────────────────────────────────────────┐
│  1. Lexer (المحلل المعجمي)                                   │
│     نص → رموز (Tokens)                                       │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  2. Parser (المحلل النحوي)                                   │
│     رموز → شجرة نحوية (AST)                                  │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  3. Type Checker (مدقق الأنواع)                              │
│     AST → AST مُتحقق منه                                     │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  4. Code Generator (مولّد الكود)                             │
│     AST → Assembly                                           │
└─────────────────────────────────────────────────────────────┘
```

## المرحلة 1: Lexer

### المهمة

تحويل النص إلى قائمة رموز.

### مثال

**المدخل:**
```arabic
س ≔ 5 + 3
```

**المخرج:**
```text
Token(ID, 'س')
Token(OP, '≔')
Token(NUM, 5)
Token(OP, '+')
Token(NUM, 3)
```

### الخوارزمية

```python
def lexer(source):
    tokens = []
    i = 0
    while i < len(source):
        char = source[i]
        
        # تجاهل المسافات
        if char.isspace():
            i += 1
            continue
        
        # الرموز
        if char in '⎕⊙≔+−·÷':
            tokens.append(Token('OP', char))
            i += 1
            continue
        
        # الأعداد
        if char.isdigit():
            num = ''
            while i < len(source) and source[i].isdigit():
                num += source[i]
                i += 1
            tokens.append(Token('NUM', int(num)))
            continue
        
        # الأسماء
        if char.isalpha():
            name = ''
            while i < len(source) and source[i].isalpha():
                name += source[i]
                i += 1
            tokens.append(Token('ID', name))
            continue
    
    return tokens
```

## المرحلة 2: Parser

### المهمة

بناء شجرة نحوية (AST) من الرموز.

### مثال

**المدخل:**
```text
Token(ID, 'س')
Token(OP, '≔')
Token(NUM, 5)
Token(OP, '+')
Token(NUM, 3)
```

**المخرج:**
```text
Assign(
    name='س',
    value=BinOp(
        op='+',
        left=Num(5),
        right=Num(3)
    )
)
```

### قواعد الأسبقية

```text
الأعلى: () استدعاء
         - سالب أحادي
         · ÷ ضرب وقسمة
         + - جمع وطرح
         = ≠ < > مقارنات
         ∧ AND
         ∨ OR
الأدنى: ؟ : شرط ثلاثي
```

## المرحلة 3: Type Checker

### المهمة

التحقق من صحة الأنواع قبل توليد الكود.

### مثال

```arabic
س ≔ 5
ص ≔ "مرحبا"
ن ≔ س + ص  # ❌ خطأ: لا يمكن جمع عدد ونص
```

### الاستنتاج التلقائي

```arabic
س ≔ 5          # نوع: عدد
ص ≔ "مرحبا"    # نوع: نص
ق ≔ ⟨1, 2, 3⟩  # نوع: قائمة أعداد
```

## المرحلة 4: Code Generator

### المهمة

توليد كود Assembly من AST.

### مثال

**المدخل:**
```text
BinOp('+', Num(5), Num(3))
```

**المخرج:**
```asm
mov rax, 5
push rax
mov rax, 3
mov rbx, rax
pop rax
add rax, rbx
```

## مُجمّعنا بالعربية

### المميزات الفريدة

1. **دعم العربية الكامل**
   - المتغيرات: `س`, `ص`, `متغير_1`
   - الرموز: `⎕`, `⊕`, `≔`
   - الرسائل: "خطأ في السطر 5"

2. **Linear Ownership (⊸)**
   - أمان ذاكرة مضمون
   - لا تسريب، لا use-after-free

3. **Arena Allocator**
   - سرعة عالية
   - لا malloc/free

4. **بدون libc**
   - استقلال تام
   - ملفات صغيرة (~500 بايت)
