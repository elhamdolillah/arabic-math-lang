## ما الذي ستتعلمه؟

### المهارات التقنية

1. **بناء مُجمّع من الصفر**
   - Lexer (المحلل المعجمي)
   - Parser (المحلل النحوي)
   - Type Checker (مدقق الأنواع)
   - Code Generator (مولّد الكود)

2. **تصميم لغة برمجة**
   - نظام الأنواع
   - الملكية الخطية (⊸)
   - إدارة الذاكرة

3. **البرمجة على مستوى منخفض**
   - x86_64 Assembly
   - Linux syscalls
   - ELF binaries

### المهارات الفكرية

1. **التفكير الرياضي**
2. **التحليل النظمي**
3. **حل المشكلات المعقدة**

## أول برنامج

### الكود

```arabic
⎕ "السلام عليكم"
```

### التشغيل

```bash
# 1. إنشاء الملف
echo '⎕ "السلام عليكم"' > hello.ar

# 2. التجميع
python3 math_complete.py hello.ar

# 3. التحويل إلى ELF
nasm -f elf64 hello.asm -o hello.o
ld hello.o -o hello

# 4. التشغيل
./hello
```

### المخرج

```
السلام عليكم
```

### ما الذي حدث؟

```text
الكود العربي → Lexer → Parser → Type Check → CodeGen → Assembly → ELF
     ⎕ "..."      🔧       🌳        🔍         ⚙️       .asm     ./hello
```
