# الفصل 9: المكتبة القياسية (Standard Library)

## مقدمة

المكتبة القياسية توفر الدوال الأساسية التي يحتاجها كل برنامج. في لغتنا، المكتبة **مدمجة في المُجمّع** ولا تحتاج استيراد.

---

## الدوال الأساسية

### الطباعة

```arabic
# طباعة نص أو عدد
⎕ "مرحبا"
⎕ 42
⎕ س
```

### القراءة

```arabic
# قراءة سطر من stdin
سطر ≔ ⊙
⎕ "أدخلت: " ⊕ سطر
```

## دوال النصوص

### الطول

```arabic
ن ≔ "مرحبا"
الطول ≔ حجم(ن)    # 10 (بايت)
```

### الدمج

```arabic
كامل ≔ "أ" ⊕ "ب" ⊕ "ج"    # "أبج"
```

### المقارنة

```arabic
م ≔ "أ" = "ب"        # 0 (خطأ)
م ≔ "أ" = "أ"        # 1 (صحيح)
م ≔ "أ" ≠ "ب"        # 1
```

### التحويل

```arabic
# عدد → نص
ن ≔ نص(42)           # "42"

# نص → عدد (قريباً)
# ع ≔ عدد("42")      # 42
```

## دوال الأعداد

### العمليات الأساسية

```arabic
جمع ≔ 5 + 3          # 8
طرح ≔ 10 - 4         # 6
ضرب ≔ 3 · 7          # 21
قسمة ≔ 20 ÷ 4        # 5
باقي ≔ 17 % 5        # 2
```

### القيم المطلقة

```arabic
م ≔ 0 - 5            # -5
مطلق ≔ م < 0 ؟ 0 - م : م    # 5
```

### القوى (قريباً)

```arabic
# م ≔ قوة(2, 10)     # 1024
```

## دوال القوائم

### الإنشاء

```arabic
ق ≔ ⟨1, 2, 3, 4, 5⟩
فارغة ≔ ⟨⟩
```

### الوصول

```arabic
أول ≔ رأس(ق)               # 1
باقي ≔ ذيل(ق)              # ⟨2, 3, 4, 5⟩
ثاني ≔ رأس(ذيل(ق))         # 2
```

### الطول

```arabic
الطول ≔ أحص(ق)             # 5
فارغ ≔ أحص(ق) = 0          # منطقي
```

### الدمج

```arabic
ق١ ≔ ⟨1, 2⟩
ق٢ ≔ ⟨3, 4⟩
مدمجة ≔ ق١ ⊕ ق٢             # ⟨1, 2, 3, 4⟩
```

## دوال الملفات

### الكتابة

```arabic
ملف ≔ فتح("test.txt")
اكتب_ملف(ملف، "السلام عليكم\n")
اكتب_ملف(ملف، "السطر الثاني\n")
اختم(ملف)
```

### القراءة

```arabic
ملف ≔ فتح("test.txt")
محتوى ≔ اقرأ_ملف(ملف، 4096)
اختم(ملف)
⎕ محتوى
```

### مثال كامل: نسخ ملف

```arabic
# قراءة من ملف
مصدر ≔ فتح("input.txt")
محتوى ≔ اقرأ_ملف(مصدر، 4096)
اختم(مصدر)

# كتابة إلى ملف آخر
هدف ≔ فتح("output.txt")
اكتب_ملف(هدف، محتوى)
اختم(هدف)

⎕ "تم نسخ الملف بنجاح"
```

## دوال المصفوفات

### المحدد

```arabic
# مصفوفة 2×2
أ ≔ 1 ⋄ ب ≔ 2
ج ≔ 3 ⋄ د ≔ 4
محدد ≔ أ · د - ب · ج        # -2
```

### الجمع

```arabic
# جمع عنصر بعنصر
أ١ ≔ 1 ⋄ ب١ ≔ 2
أ٢ ≔ 5 ⋄ ب٢ ≔ 6
أ_ج ≔ أ١ + أ٢
ب_ج ≔ ب١ + ب٢
```

## دوال AI (متقدمة)

### البوابات المنطقية

```arabic
# AND
و ≡ λ(س، ص). س · ص > 0

# OR
أو ≡ λ(س، ص). س + ص > 0

# NOT
لا ≡ λ(س). س = 0
```

### XOR (متعددة الطبقات)

```arabic
xor ≡ λ(س، ص). ﴿
    ناتج_or ≔ س + ص > 0
    ⋄ ناتج_nand ≔ 0 - س - ص + 2 > 0
    ⋄ ناتج_or · ناتج_nand
﴾

⎕ xor(1, 0)    # 1
⎕ xor(1, 1)    # 0
```

## دوال رياضية متقدمة

### التفاضل

```arabic
# f(x) = ax² + bx + c
# f'(x) = 2ax + b

مشتقة ≡ λ(أ، ب، س). 2 · أ · س + ب
⎕ مشتقة(3, 2, 1)    # 8
```

### التكامل

```arabic
# ∫₀² (6x² + 4x + 2) dx = [2x³ + 2x² + 2x]₀² = 28

تكامل ≡ λ(أ، ب، ج، حد). أ ÷ 3 · حد³ + ب ÷ 2 · حد² + ج · حد
⎕ تكامل(6, 4, 2, 2)    # 28
```

## جدول الدوال الكامل

| الدالة | النوع | الوصف |
|--------|-------|-------|
| `⎕` | stmt | طباعة |
| `⊙` | expr | قراءة من stdin |
| `حجم` | نص → عدد | طول النص |
| `نص` | عدد → نص | تحويل إلى نص |
| `رأس` | قائمة → عنصر | العنصر الأول |
| `ذيل` | قائمة → قائمة | الباقي |
| `أحص` | قائمة → عدد | الطول |
| `فتح` | نص → ملف | فتح ملف |
| `اختم` | ملف → وحدة | إغلاق ملف |
| `اكتب_ملف` | ملف × نص → وحدة | كتابة |
| `اقرأ_ملف` | ملف × عدد → نص | قراءة |
| `عروة` | () → مقبض | إنشاء socket |

## الخلاصة
