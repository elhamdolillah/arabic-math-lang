# الفصل الثالث: المحلل النحوي (Parser)

## 3.1 التعبيرات

أعداد، نصوص، متغيرات، عمليات حسابية (`+ - ·`)، دمج `⊕`، الشروط الثلاثية `؟ :`.

## 3.2 البيانات

- `أ ≔ 5` — إسناد
- `د ≡ λس. س + 1` — تعريف دالة
- `⎕ "نص"` — طباعة

## 3.3 الكتل ﴿ ﴾

الكتل تحصر نطاقًا: `μ` للحلقات، `∀` للتكرار، وجسم الدالة.

## 3.4 الدوال λ

الإغلاق يلتقط المتغيرات الحرة في بيئة runtime، وتُخزَّن كـ closure struct على arena.

## 3.5 التطابق الأنماطي

`طابق ع : ﴿ ن ⇒ ن ⇒ ... ﴾` — سبعة أنماط (انظر الفصل السابع).

## 3.6 الأنواع الجبرية

`نوع شكل : ﴿ دائرة(ن) ⋄ مستطيل(ع، ا) ﴾` — بناة sum/product types (الفصل الثامن).

## 3.7 السمات

```arabic
سمة مساحة(ن) : ﴿ احسب : ن → عدد ﴾
تطبيق مساحة على شكل : ﴿ احسب(ش) ≔ ... ﴾
```

(الفصل التاسع)
