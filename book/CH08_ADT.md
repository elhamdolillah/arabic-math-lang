# الفصل الثامن: الأنواع الجبرية

## 8.1 Sum Types

```arabic
نوع شكل : ﴿ دائرة(ن) ⋄ مستطيل(ع، ا) ﴾
```

`وسم` (tag) عند +8 يميّز الباني.

## 8.2 Product Types

الباني `مستطيل(3، 4)` يُخزِّن حقلين متتاليين عند +16، +24.

## 8.3 البناء عبر البناة

`د ≔ دائرة(5)` يخصص heap جديدًا ويكتب الوسم والحقول.

## 8.4 التطابق مع البناة

```arabic
طابق ش : ﴿
    دائرة(ن) ⇒ 3 · ن · ن
    ⋄ مستطيل(ع، ا) ⇒ ع · ا
﴾
```
