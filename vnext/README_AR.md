# UORI v9 — الإصدار الدستوري المعزول

هذا المجلد هو إعادة بناء معزولة لمشروع UORI. لا يستبدل النسخة الحالية ولا يُعتمد في الفرع الرئيسي قبل اكتمال بوابة القبول.

## مبدأ الإصدار

كل مكوّن في هذا الإصدار يجب أن يملك مواصفة واضحة، ومالكاً واحداً للبيانات أو المورد، ونمط دليل معلناً، واختباراً قابلاً لإعادة التشغيل. ولا تُنقل أي نتيجة من طبقة الاقتراح إلى طبقة القرار إلا بعد استيفاء الدليل المطلوب.

## حدود الإصدار الأول

يبدأ الإصدار بنواة حتمية صغيرة للأنواع والملكية والنتائج، ثم يضيف التعليمات والبيانات والملفات ومسارات الإدخال والإخراج. ولا تُدرج الدوال العددية أو تعليمات Assembly في النواة الجديدة إلا إذا كانت لها مواصفة وحد خطأ واختبار عتاد وربط رسمي مناسب.

## طبقات البناء

| الطبقة | المسؤولية | شرط القبول |
|---|---|---|
| التعليمات | تعريف العملية المسموح بها ودلالتها | معنى واحد واختبار دلالي |
| البيانات | نوع البيانات ومجاله وملكيته ومصدره | مخطط صالح وحدود معلومة |
| الملفات | القراءة والكتابة والهوية والتجزئة | ملكية خطية وسجل أثر |
| التنفيذ | تحويل العقد إلى كود سريع | تكافؤ مرجعي وقياس أداء |
| الدليل | تصنيف النتيجة وقرار الامتناع | وسم دليل متسق |

## قاعدة الأداء

الأولوية للسرعة بعد ثبوت الصحة، لا قبلها. تُقاس السرعة مقابل مرجع واضح، وتُسجل البيئة وعدد التكرارات والنتيجة. لا يُقبل تحسين أداء يغير السلوك الموثق أو يتجاوز حد الخطأ `16`.

## قاعدة التدرج

الإصدار الحالي هو **إطار إعادة بناء قابل للتحقق**. لا يجوز وصفه بأنه مترجم مكتمل أو بديل كامل للنسخة السابقة حتى تنجح مراحل النواة، والتعليمات، والبيانات، والملفات، ثم الاختبارات الرسمية والعددية والعتادية.
