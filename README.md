# 🕌 اللغة العربية الرياضية
## Arabic Mathematical Language

> ﴿بسم الله الرحمن الرحيم﴾
>
> لغة برمجة عربية رياضية كاملة، مُجمّعة إلى x86_64 مباشرة، بدون أي اعتماديات خارجية.

---

## 🌟 المميزات الرئيسية

### ⚡ الأداء والأمان
- **AOT Compilation**: تجميع مباشر إلى x86_64 Linux (syscalls خام)
- **بدون libc**: استقلال تام، ملفات ELF صغيرة
- **Linear Ownership (⊸)**: أمان ذاكرة مضمون في وقت التجميع
- **Arena Allocator**: لا تسريب ذاكرة

### 🧮 البنية الرياضية
- **صياغة رياضية**: `≔` للإسناد، `μ` للحلقات، `∀` للتكرار
- **نظام أنواع**: استنتاج تلقائي (عدد، نص، قائمة، دالة)
- **دوال عالية الرتبة**: `λ` مع closures
- **شروط ثلاثية**: `؟ :`

### 🕌 الدستور القرآني
كل ميزة مستمدة من آية قرآنية:
- ﴿كتاب أحكمت آياته﴾ → الإحكام والدقة
- ﴿وإنا له لحافظون﴾ → أمان الذاكرة
- ﴿وضع الميزان﴾ → التوازن والعدل

## 🚀 البدء السريع

### المتطلبات
- Linux x86_64
- Python 3.6+
- NASM
- GNU ld

### التثبيت
```bash
git clone https://github.com/elhamdolillah/arabic-math-lang.git
cd arabic-math-lang
sudo apt install python3 nasm binutils
```

### التجميع والتشغيل
```bash
python3 math_complete.py hello.ar
nasm -f elf64 hello.asm -o hello.o
ld hello.o -o hello
./hello
```
