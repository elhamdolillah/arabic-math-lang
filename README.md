# اللغة الرياضية العربية 🕌

**أول لغة برمجة عربية كاملة تُجمَّع AOT إلى ثنائيات ELF مستقلة بلا libc**

> **منهج الفصل بين المشروعين:** هذا المستودع هو المشروع الأساسي المستقل — اللغة العربية الرياضية نفسها (المحرك، الدستور، الورقة البحثية، قانون القرآن). التطبيق المحمول هو **نتاج منفصل ومستقل** في مستودع آخر [vps-agent](https://github.com/elhamdolillah/vps-agent) له حياته وتوثيقه وإهدائه المستقل؛ اللغة تخدم التطبيق والعكس صحيح دون أي اندماج تاريخي أو تقني بين المستودعين.

> **«كِتَابٌ أُحْكِمَتْ آيَاتُهُ»** — كل رمز محكم، كل مبدأ مُثبت

---

## 🎯 ما هي هذه اللغة؟

لغة برمجة عربية رياضية تُجمَّع مباشرة إلى:

```
مصدر عربي → Python → NASM → ld → ELF مستقل (بدون libc)
```

كل شيء مبني من الصفر:

- ✅ Lexer + Parser + Type Inference + CodeGen
- ✅ Arena Allocator (256KB)
- ✅ Linear Ownership (⊸) — مثل Rust
- ✅ Pattern Matching — مثل Haskell/Erlang
- ✅ Algebraic Data Types — مثل OCaml/Rust
- ✅ Traits/Typeclasses — مثل Rust/Haskell
- ✅ Threads حقيقية — `clone` syscall
- ✅ Channels — `pipe2` syscall
- ✅ Self-hosting — المُجمّع يجمّع نفسه


### مثال: Hello World

```arabic
⎕ "مرحبا بالعالم"
```

### مثال: مضروب (Factorial)

```arabic
مضروب ≡ λن. طابق ن : ﴿
    0 ⇒ 1
    ⋄ س ⇒ س · مضروب(س - 1)
﴾
⎕ نص(مضروب(5))    # 120
```

### مثال: أنواع جبرية + سمات

```arabic
نوع شكل : ﴿ دائرة(ن) ⋄ مستطيل(ع، ا) ﴾

سمة مساحة(ن) : ﴿ احسب : ن → عدد ﴾

تطبيق مساحة على شكل : ﴿
    احسب(ش) ≔ طابق ش : ﴿
        دائرة(ن) ⇒ 3 · ن · ن
        ⋄ مستطيل(ع، ا) ⇒ ع · ا
    ﴾
﴾

⎕ نص(احسب(دائرة(5)))      # 75
⎕ نص(احسب(مستطيل(3، 4)))  # 12
```
