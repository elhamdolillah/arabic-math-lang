# خلاصة فهارس كتب الرياضيات — بحث إزالة التكرار

## المصادر المقروءة

1. Open Access Texts — Mathematics: https://openaccesstexts.com/math/
   يغطي الفهرس: الجبر المجرد، الهندسة الجبرية، التفاضل، التوافقيات والرياضيات المتقطعة، التحليل العقدي، المعادلات التفاضلية، الجبر الابتدائي، الهندسة، الجبر الخطي، المنطق، الحوسبة الرياضية والتحليل العددي، نظرية الأعداد، الاحتمالات، البراهين، التحليل الحقيقي، الإحصاء، المثلثات.

2. American Institute of Mathematics Open Textbook Initiative — Approved Textbooks: https://textbooks.aimath.org/textbooks/approved-textbooks/
   الفهرس يصنف كتباً مفتوحة حسب المقرر، وتشمل: الجبر والدوال، التفاضل، الجبر الخطي، المعادلات التفاضلية، البراهين، نظرية الألعاب، الرياضيات المتقطعة، التوافقيات، الحساب والتحليل العددي، نظرية الأعداد، الجبر المجرد، التحليل الحقيقي والعقدي، الهندسة والطوبولوجيا، الاحتمالات، الإحصاء، المنطق، والرياضيات لتعلم الآلة.

3. Oscar Levin, Discrete Mathematics: An Open Introduction (4th ed.): https://discrete.openmathbooks.org/
   الموضوعات الأربعة الرئيسية: المنطق، نظرية الرسوم، العد، والمتتاليات؛ وتظهر أيضاً المجموعات والدوال والعلاقات، الاستقراء، البرهان بالتناقض، البراهين التوافقية، الدوال المولدة، ونظرية الأعداد. الصفحة تصف النص بأنه مفتوح المصدر ومتاح إلكترونياً وPDF، مع ترخيص CC BY-NC-SA 4.0.

4. Open Textbook Library — Mathematics: https://open.umn.edu/opentextbooks/subjects/mathematics
   يعرض كتباً مثل الجبر الخطي، البراهين، التفاضل، الإحصاء، الاحتمالات، والهندسة، ويذكر تراخيصها لكل كتاب. الصفحة كانت معروضة من مخزن محلي مؤقت عند الاستخراج.

## مفاهيم غير مكررة مرشحة لـUORI

- تمثيل الأعداد الصحيحة والكسور والحساب الثابت.
- فواصل validated intervals وحدود الخطأ المحافظة.
- تحقق أبعاد المتجهات والمصفوفات قبل العمليات.
- ترتيب جمع ثابت وتجميع شجري حتمي.
- منطق القضايا، المجموعات، الدوال، العلاقات، والاستقراء.
- الرسوم البيانية، المسارات، والمكونات المتصلة.
- المتتاليات والدوال المولدة.
- الجبر الخطي: الأنظمة، المصفوفات، المحددات، القيم الذاتية.
- التحليل: النهايات، الاستمرارية، التكامل، وسلاسل التقريب مع شروط إثبات.
- المعادلات التفاضلية: الحلول العددية مع معيار توقف وحد خطأ.
- الاحتمالات والإحصاء: عينات ومقدرات مثبتة مع فصل التقدير عن الحقيقة.
- المنطق الرسمي والتحقق البرهاني.
- الحوسبة الرمزية والتحليل العددي الموثق.

## ملاحظات إزالة التكرار

الأسماء المتكررة عبر Open Access Texts وAIM وOpen Textbook Library لا تمثل قواعد جديدة؛ جرى احتسابها كمراجع متعددة للمفهوم نفسه. لم يُعتبر وجود كتاب إضافي دليلاً على قابلية التنفيذ. كل قاعدة تحتاج تمثيلاً canonical، حدود فشل، اختباراً حتمياً، وبصمة أدلة.

## قيد المصدر

هذه نتائج فهارس ومحتويات، وليست استخراجاً كاملاً لكل فصل أو نظرية. لا يجوز نسب تفاصيل نظرية لمصدر لم تُقرأ صفحته الداخلية أو فهرسه التفصيلي.
