# مراجعة دستورية لقواعد الرياضيات قبل الاعتماد

**الحالة:** مراجعة حوكميّة مستقلة؛ ليست اعتماداً تنفيذياً ولا تعديلاً للـwheel المجمد.

**المرجع المجمد:** `uori-wave77-freeze-2026-08-24` / `f56b8bd`

**النطاق:** تطبيق خريطة الموضوعات المستخرجة من فهارس ومناهج رياضيات مفتوحة على دستور اللغة العربية الرياضية وملحق دستور UORI، مع تصنيف كل قاعدة وفق الحالات `PROVEN` و`POLICY` و`RESEARCH` و`ABSTAIN`.

## 1. قاعدة القرار

لا يكفي أن يكون الموضوع شائعاً في كتاب أو منهج لكي يدخل Tier-0. الفهرس يثبت وجود الموضوع في الأدبيات التعليمية، لكنه لا يثبت تمثيله في MAL، ولا حتميته على ABI، ولا سلامة حدوده. لذلك لا ينتقل أي موضوع إلى حالة تنفيذية إلا بعد تعريف canonical، وترتيب عمليات ثابت، وحدود موارد، وحالات فشل، واختبار خام قابل لإعادة التشغيل، وبصمة مستقلة.

> **قاعدة دستورية:** عند غياب التعريف أو الدليل أو حد الخطأ، يكون القرار `CLASS=ABSTAIN` و`EXECUTION=NOT_PERFORMED`.

## 2. الاختبار الدستوري

طبقت المراجعة الشروط الآتية المستمدة من الملحق الدستوري: عدم تعديل الأساس، الفصل بين البحث والتنفيذ، منع `eval` و`exec` و`source_ref` غير الموثق، عدم قراءة الساعة داخل المسار الحتمي، رفض NaN وInfinity، ثبات الترتيب والوقود، حماية الشكل والأبعاد، وتسجيل المصدر والبصمة وحالة التنفيذ. كما طُبقت مادة 13: الزمن لا يحوّل النموذج الاحتمالي إلى حقيقة؛ بل يسمح بتقدير حتمي مشروط فقط عند تثبيت الشواهد والمقدر وحد الخطأ.

## 3. مصفوفة العائلات الثماني

| العائلة | ما تؤيده الفهارس | القرار قبل الاعتماد | سبب القرار الدستوري | المسار التالي |
|---|---|---|---|---|
| الجبر | التعبيرات، الدوال، الجبر المجرد، كثيرات الحدود، نظرية الأعداد | `POLICY` للقواعد الرمزية المحدودة؛ `ABSTAIN` للتوسعات غير المعرفة | يلزم grammar وcanonical ordering وتعريف المجال والقسمة والجذر | تثبيت مجموعة عمليات صغيرة واختبارات الهوية |
| الجبر الخطي | الأنظمة، المصفوفات، الفضاءات، التحويلات، المحددات والقيم الذاتية | `POLICY` لشروط الشكل؛ `ABSTAIN` للحل العددي غير المثبت | الشكل قابل للحتمية، لكن الاستقرار العددي والتقريب يحتاجان حد خطأ وإصدار ABI | اعتماد shape constraints أولاً؛ إبقاء eigensolver خارج Tier-0 |
| الاحتمالات | الأحداث، الاحتمال الشرطي، التوزيعات، القيمة المتوقعة، الإحصاء | `POLICY` للمقدر المحدد بعينة وشاهد؛ `ABSTAIN` للتنبؤ بالحقيقة أو العشوائية غير المثبتة | مادة 13 تفصل بين estimate مشروط والحقيقة المستقبلية | تعريف estimator وبذرة/شاهد وسجل خطأ؛ لا قرار تنبؤي عام |
| المنطق | القضايا، الروابط، الجداول، التكافؤ، الاستدلال، البرهان والاستقراء | `POLICY`؛ ويمكن أن تصبح `PROVEN` لكل subset بعد corpus واختبار | قواعد الحقيقة والتكافؤ قابلة للحساب الحتمي إذا ثُبتت اللغة والحدود | بناء corpus صغير للمنطق مع حد عمق ووقود |
| المعادلات التفاضلية | IVP/BVP، طرق Euler وRunge–Kutta، الحلول العددية | `RESEARCH`؛ `ABSTAIN` عند غياب فرضيات الاستقرار وحد الخطأ | التقريب لا يثبت الحل؛ يلزم مجال وشروط ابتدائية ومخطط وخطأ | دراسة خوارزمية واحدة فقط مع convergence guard |
| الهندسة | القياس، الزوايا، المضلعات، التحويلات، الهندسة التحليلية والطوبولوجيا التمهيدية | `POLICY` للهندسة الصحيحة/الرمزية؛ `ABSTAIN` للرسم من صورة أو القياس الضوضائي | الرسم ليس دالة وحيدة بلا نظام إحداثيات وعينة وقاعدة استيفاء، وفق مادة 13 | اعتماد primitives رمزية محدودة؛ لا OCR/vision في المسار الحتمي |
| الرياضيات المتقطعة | المجموعات، العلاقات، الرسوم، العد، المتتاليات، الت合同ات، الدوال المولدة | `POLICY`؛ وبعضها مرشح `PROVEN` بعد corpus | البنى المنتهية قابلة للتمثيل، لكن حدود الحجم والعمق لازمة | أولوية graph/set/sequence بترميز canonical |
| الحوسبة الرمزية والتحليل العددي | البحث عن الجذور، الاستيفاء، التكامل العددي، ODE، Sage والحساب الموثق | `POLICY` كحواجز وشهادات؛ `ABSTAIN` كتنفيذ عام | لا يجوز إعلان نتيجة تقريبية دون معيار توقف وحد خطأ ووقود | تنفيذ interval arithmetic وconvergence witness فقط، لا solver عام |

## 4. القواعد التي اجتازت التدقيق المبدئي

### 4.1 الحساب النسبي والفاصل

حساب الأعداد الصحيحة والكسور النسبية وقواعد الفواصل الأربع يطابق مبادئ الحتمية إذا كان الإدخال canonical، وكانت القسمة على صفر مرفوضة، ولم تُسقط حدود المجال. هذه القواعد مصنفة `POLICY` في الدستور و`PROVEN` فقط داخل امتداد Python الذي اختبرناه بنطاقه الحالي؛ لا تعني أنها مثبتة داخل kernel أو WASM.

### 4.2 شروط الشكل

فحص أطوال المتجهات وأبعاد المصفوفات قبل العملية قاعدة دستورية آمنة. لا يسمح بالتوسيع الضمني أو broadcasting غير المعلن. التصنيف الحالي `POLICY + EXTENSION_PROVEN`، وليس `KERNEL_PROVEN`.

### 4.3 التجميع الحتمي

الشجرة الثنائية والترتيب الثابت ونافذة الوقود قاعدة متوافقة مع الدستور. التصنيف `POLICY + MODEL_PROVEN` ضمن النموذج أحادي العملية؛ أما التوازي الفعلي وتساوي بصمته مع المسار المرجعي فيبقيان `ABSTAIN_UNTIL_EVIDENCE`.

### 4.4 حارس التقارب

وجود معيار توقف وحد خطأ وميزانية وقود شرط قبول وليس برهاناً تلقائياً على صحة الخوارزمية. إذا لم يتحقق الشرط قبل نفاد الوقود فالقرار `ABSTAIN / CONVERGENCE_UNPROVEN`. تصنيف الحارس `EXTENSION_PROVEN` بحدوده الحالية؛ أما كل خوارزمية تقريبية جديدة فتحتاج إثباتاً منفصلاً.

## 5. قواعد لم تعتمد

| القاعدة | التصنيف | سبب الامتناع |
|---|---|---|
| حساب عائم عام | `ABSTAIN` | NaN/Infinity والتقريب وسلوك FPU غير محددة ضمن العقد |
| قيمة ذاتية أو حل نظام تقريبي عام | `ABSTAIN_UNTIL_EVIDENCE` | الاستقرار، التكرار، وحد الخطأ غير مثبتة لكل مجال |
| رسم دالة من صورة | `ABSTAIN` | الصورة لا تحدد دالة وحيدة؛ يلزم OCR وإحداثيات واستيفاء موثق |
| استعادة دالة من نقاط بلا قاعدة استيفاء | `ABSTAIN` | تعدد الدوال الممكنة |
| تنبؤ سلسلة noisy كحقيقة | `ABSTAIN` | النموذج والهدف وحد الخطأ خارج العينة غير مثبتة |
| تكامل أو تفاضل عددي بلا مجال ومخطط وخطأ | `ABSTAIN` | لا توجد دلالة حتمية كافية |
| solver عام للمعادلات التفاضلية | `RESEARCH` | يتطلب عقود استقرار وتحققاً مستقلاً |
| عشوائية فعلية أو مصدر شبكي أثناء القرار | `ABSTAIN` | محظورة في المسار الحتمي وغير قابلة لإعادة الإنتاج دون شاهد صريح |

## 6. قرار الاعتماد المرحلي

لا يُعتمد أي موضوع جديد داخل دستور اللغة أو UORI بوصفه قاعدة تنفيذية عامة في هذه المرحلة. يعتمد هذا الملف كـ**حاجز مراجعة** يحدد ما يلي:

1. **مقبول كسياسة تصميم:** الفواصل المحافظة، شروط الشكل، التجميع الثابت، وحارس التقارب.
2. **قابل لإثبات محدود:** الحساب النسبي والفاصل، ضمن الامتداد المختبر فقط وبلا ادعاء دمج kernel.
3. **يبقى بحثاً:** الجبر الخطي العددي، ODE، الاستيفاء العام، والحلول الرمزية المفتوحة.
4. **يمتنع افتراضياً:** الصور والقياسات الضوضائية، التنبؤ غير المشروط، العشوائية غير المشهودة، والتنفيذ الخارجي.

وبالتالي فإن نتيجة التدقيق قبل الاعتماد هي:

```text
CONSTITUTION_REVIEW=PASS_WITH_GUARDS
RULES_EXECUTIVELY_ADOPTED=0
POLICY_RULES_ACCEPTED=4
EXTENSION_SCOPED_PROVEN=4
RESEARCH_RULES=4
ABSTAIN_RULES=8
BASELINE_MODIFIED=NO
SOURCE_EXECUTION=NOT_PERFORMED
NETWORK=DISABLED_BY_CONTRACT
```

الأرقام أعلاه هي عدّادات تصنيف لهذه المراجعة، وليست قياسات أداء ولا عدد نظريات الرياضيات. ولا تغير هذه النتيجة دستوراً سابقاً أو ABI أو wheel المجمد. أي اعتماد تنفيذي لاحق يحتاج فرعاً مستقلاً، عقداً، corpus، stdout خاماً، بصمة، وتحقق سلسلة.
