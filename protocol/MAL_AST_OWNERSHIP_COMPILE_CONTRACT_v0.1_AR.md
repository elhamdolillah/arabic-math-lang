# عقد واجهة AST والملكية والترجمة — الإصدار 0.1

تستخدم واجهة AST معرفات عقد وفهارس قيم فقط. كل عقدة تملك حقولها الفهرسية داخل Arena، ولا تنتقل ملكية قيمة إلا عبر `value_id` صحيح ومثبت النطاق.

## الأنواع والمجالات

الأنواع المسموح بها في هذه المرحلة هي: رمز، سلسلة، عدد صحيح، عدد حقيقي canonical، وقائمة معاملات محدودة. أي نوع غير مسجل في المخطط يعاد معه `ABSTAIN / UNKNOWN_AST_KIND`. وكل قيمة خارج المجال تعاد معها `ABSTAIN / SHAPE_MISMATCH`.

## الملكية وبلا تخصيص

تُنشأ العقد في Arena ثابتة السعة. لا تخصيص ديناميكي أثناء التحليل أو التطبيع أو التوليد. إذا نفدت السعة أو ظهر إدراج بعد الإغلاق، فالنتيجة `ABSTAIN / ARENA_EXHAUSTED`.

## عند الترجمة

تنفذ `عند_الترجمة` على AST canonical فقط، وبإعدادات immutable وبصمة configuration معلومة. لا تقرأ الساعة ولا الشبكة ولا البيئة. إذا تعذر إثبات التطابق بين `config_hash` المرفق والحالة الحالية، فالقرار `ABSTAIN / CONFIG_HASH_MISMATCH`.

لا يُسمح بتحويل نتيجة بحث أو مصدر نصي إلى تنفيذ. المسار هو `Lookup → Authorize → Bridge`، وتبقى `SOURCE_REF_EXECUTED=NO` في المراجعة الحالية.

| القاعدة | التصنيف |
|---|---|
| فهرسة AST وملكية Arena | `POLICY` |
| بلا تخصيص أثناء المسار الحتمي | `POLICY` |
| عند الترجمة مع بصمة إعدادات | `RESEARCH` حتى التنفيذ |
| نوع غير معروف أو مجال غير مطابق | `ABSTAIN` |
| مشغل MAL غير متاح | `ABSTAIN` |
