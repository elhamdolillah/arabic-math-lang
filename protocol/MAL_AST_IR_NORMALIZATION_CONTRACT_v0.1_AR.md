# عقد التحويل والتطبيع بين AST وIR — الإصدار 0.1

يُحوَّل AST إلى تمثيل وسيط `IR` عبر مسار أحادي الاتجاه ومحدد الترتيب. لا يُنشأ أي عقد جديد خارج Arena، ولا تُستخدم معرفات مشتقة من العنوان أو الزمن أو ترتيب hash غير مقرر.

## قواعد التطبيع

يُطبع كل رمز إلى ترميز UTF-8 canonical، وتُطبع الأعداد الحقيقية إلى تمثيل عشري منتهٍ مثبت دون تقريب ضمني. تُرتب المعاملات حسب ترتيب ظهورها في المصدر، وتُحفظ العقد بحسب `node_id` المتزايد. لا يسمح العقد بإعادة ترتيب دلالي إلا إذا كان التحويل مسجلاً صراحة في مخطط الإصدار.

## التحويل المسموح

يقبل التحويل عقد AST معروف النوع، مكتمل الحقول، سليم الفهارس، ومطابقًا لبصمة الإعدادات. عند نجاح التحويل تُنتج كل تعليمة IR رقمًا تسلسليًا ثابتًا، ويُشتق `ir_hash` من التمثيل canonical فقط.

## الامتناع

تكون النتيجة `ABSTAIN` عند النوع المجهول، أو المجال غير المطابق، أو الحقل المفقود، أو عدم تطابق `config_hash`، أو ظهور تحويل ضمني، أو محاولة ترتيب غير مقرر، أو تجاوز Arena أو الوقود. لا يُنتج IR جزئي على أنه مكتمل.

| الحارس | القرار |
|---|---|
| AST غير canonical | `ABSTAIN / AST_NOT_CANONICAL` |
| تحويل ضمني | `ABSTAIN / IMPLICIT_CONVERSION` |
| نوع غير معروف | `ABSTAIN / UNKNOWN_AST_KIND` |
| بصمة إعدادات مختلفة | `ABSTAIN / CONFIG_HASH_MISMATCH` |
| اكتمال ناجح | `PASS / IR_CANONICAL_READY` |

التصنيف الدستوري لهذا العقد `POLICY` من جهة الترتيب والامتناع، و`RESEARCH` من جهة التنفيذ، لأن مشغل MAL الموثوق غير متاح. حالة التشغيل الحالية `SOURCE_REF_EXECUTED=NO`.
