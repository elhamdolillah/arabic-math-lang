# سجل الأدلة الحاكم للآليات 183–185

## 183 — `__slots__` في Python

يوثق مرجع نموذج البيانات في Python أن `__slots__` يتيح التصريح الصريح بأعضاء البيانات ويمنع إنشاء `__dict__` و`__weakref__` في الحالات التي ينطبق عليها التعريف. هذا يقيّد مجموعة السمات القابلة للوصول على مستوى نموذج الكائن، لكنه لا يثبت تخطيط ذاكرة ABI ثابتًا، ولا يثبت سرعة ثابتة أو دالة نقية؛ فالتنفيذ قد يختلف بين CPython وإصدارات أو تطبيقات Python أخرى، كما أن الوراثة ووجود صنف أساس ذي `__dict__` أو `__weakref__` يغيران النتيجة.

المصدر: https://docs.python.org/3/reference/datamodel.html

## 184 — الأعمدة المولدة المخزنة في PostgreSQL

يوضح توثيق PostgreSQL أن العمود المولد يحسب من أعمدة أخرى، وأن النوع المخزن يحسب عند الكتابة ويشغل تخزينًا، ولا يمكن الكتابة إليه مباشرة. كما يفرض التوثيق قيودًا مهمة، منها الاقتصار على الدوال immutable وعدم استخدام الاستعلامات الفرعية أو مراجع خارج الصف. لذلك يمكن قبول حتمية مشروطة بنطاق مخطط قاعدة البيانات وتعبير immutable وإصدار محرك محدد. لا يجوز تعميمها على كل SQL أو اعتبارها مستقلة عن نوع العدد والتقريب والدقة والامتدادات والمشغلات.

المصدر: https://www.postgresql.org/docs/current/ddl-generated-columns.html

## 185 — `object` في Kotlin

تنص وثائق Kotlin على أن تهيئة إعلان object آمنة للخيوط وتتم عند أول وصول، وأن الإعلان ينشئ singleton لغويًا. هذا يثبت ضمانًا محدودًا لسلامة التهيئة ووحدة الوصول ضمن نموذج Kotlin والمنصة المستهدفة. لكنه لا يثبت أن الحالة الداخلية immutable، ولا يثبت نقاء المهيئ، ولا يثبت حتمية الآثار الجانبية أو ترتيب الخيوط بعد التهيئة، ولا يلغي فروق المنصات أو الاستثناءات أثناء التهيئة.

المصدر: https://kotlinlang.org/docs/object-declarations.html
