# عقد التوليد وABI الحتمي — الإصدار 0.1

يستقبل مولد MAL تمثيل IR canonical فقط. ويصدر تعليمات مرتبة وفق `ordinal` ثابت، مع أسماء رموز مشتقة من معرفات منطقية canonical لا من عناوين أو مسارات مطلقة.

يُثبت ABI حجم الأنواع، ترتيب المعاملات، محاذاة السجلات، وقواعد حالة الخطأ في إصدار العقد. لا يعتمد التوليد على جدولة الخيوط أو ترتيب النظام أو عشوائية المترجم.

تُرفض أية تعليمة غير معروفة أو قيمة خارج المجال أو رمز مكرر. وتكون النتيجة `ABSTAIN / UNKNOWN_OPCODE` أو `ABSTAIN / ABI_MISMATCH` أو `ABSTAIN / SYMBOL_COLLISION` حسب السبب.

| العنصر | القاعدة |
|---|---|
| مصدر التوليد | IR canonical |
| ترتيب التعليمات | `ordinal` تصاعدي |
| أسماء الرموز | معرف منطقي canonical |
| الجدولة | ممنوعة |
| المؤشرات الخام | مرفوضة |
| ABI غير مطابق | `ABSTAIN` |
| تنفيذ المصدر | `SOURCE_REF_EXECUTED=NO` |

التصنيف `POLICY` لقواعد ABI والترتيب، و`RESEARCH` للتنفيذ الفعلي حتى يتوافر runtime موثوق.
