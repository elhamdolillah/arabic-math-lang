# مواصفة لغة MAL Grammar v0.1

**الحالة:** مسودة قابلة للتجميد بعد اجتياز corpus

**النطاق:** lexer/parser/AST للغة العربية الرياضية MAL، دون ادعاء اكتمال semantic checker أو IR أو backend native.

## 1. هوية المواصفة

| الحقل | القيمة |
|---|---|
| اللغة | MAL — Mathematical Arabic Language |
| الإصدار | `0.1.0` |
| الترميز | UTF-8 |
| التطبيع | Unicode NFC قبل التحليل |
| نهاية السطر | LF (`\\n`) |
| التعليقات | `//` حتى نهاية السطر |
| نقطة الدخول | `برنامج` |
| المخرج | AST canonical أو تشخيص حتمي |
| المصدر غير الموثوق | لا يُنفذ؛ يُحلل ساكنياً فقط |
| unknown construct | رفض نحوي أو `ABSTAIN` وفق عقد البوابة |

## 2. الكلمات المحجوزة والأنواع

الكلمات المحجوزة في الإصدار هي:

```text
بنية إذا وإلا لكل أرجع ثابت صحيح خطأ منطقي
```

والأنواع الأساسية هي:

```text
عدد_صحيح عدد_حقيقي منطقي نص بايت فراغ
```

المعرف يبدأ بحرف لاتيني أو عربي معتمد، ثم يجوز أن يتبعه حرف أو رقم أو `_`. لا يجوز استعمال كلمة محجوزة كمعرف.

## 3. القواعد النحوية EBNF

```ebnf
برنامج       ::= عنصر* EOF ;
عنصر         ::= بنية | دالة | تصريح ;
بنية         ::= "بنية" معرف "{" تصريح* "}" ";"? ;
دالة         ::= نوع معرف "(" معاملات? ")" كتلة ;
معاملات      ::= تصريح_معامل ("," تصريح_معامل)* ;
تصريح_معامل  ::= "ثابت"? نوع معرف ;
تصريح        ::= "ثابت"? نوع معرف ("=" تعبير)? ";" ;
كتلة         ::= "{" أمر* "}" ;
أمر          ::= تصريح
               | "أرجع" تعبير? ";"
               | "إذا" "(" تعبير ")" كتلة ("وإلا" كتلة)?
               | "لكل" "(" تهيئة_تكرار? ";" تعبير? ";" تحديث_تكرار? ")" كتلة
               | تعبير ";" ;
تهيئة_تكرار  ::= تصريح ;
تحديث_تكرار  ::= تعبير ;
نوع          ::= "عدد_صحيح" | "عدد_حقيقي" | "منطقي"
               | "نص" | "بايت" | "فراغ" ;
تعبير        ::= تعبير_تعيين ;
تعبير_تعيين  ::= معرف "=" تعبير_تعيين | تعبير_أو ;
تعبير_أو     ::= تعبير_و ("||" تعبير_و)* ;
تعبير_و      ::= تعبير_مقارنة ("&&" تعبير_مقارنة)* ;
تعبير_مقارنة ::= تعبير_جمع (("==" | "!=" | "<" | ">" | "<=" | ">=") تعبير_جمع)* ;
تعبير_جمع    ::= تعبير_ضرب (("+" | "-") تعبير_ضرب)* ;
تعبير_ضرب    ::= أولي (("*" | "/" | "%") أولي)* ;
أولي         ::= عدد | نص | "صحيح" | "خطأ"
               | استدعاء | معرف | "(" تعبير ")" ;
استدعاء      ::= معرف "(" (تعبير ("," تعبير)*)? ")" ;
عدد          ::= عدد_صحيح | عدد_حقيقي ;
```

ملاحظة: قاعدة `عدد_حقيقي` موجودة في grammar لأغراض التحليل، لكنها لا تعني قبول الحساب العائم في المسار الحتمي أو Tier-0. يلزم عقد IEEE-754 مستقل قبل اعتماد تنفيذها.

## 4. ترتيب العمليات

من الأعلى إلى الأدنى:

| الرتبة | العمليات |
|---:|---|
| 7 | `* / %` |
| 6 | `+ -` |
| 5 | `< > <= >=` |
| 4 | `== !=` |
| 3 | `&&` |
| 2 | `||` |
| 1 | `=`، يمينياً |

لا توجد معاملات أحادية في v0.1. استعمال `-س` أو `!س` كمعامل أحادي خارج corpus الإصدار يؤدي إلى رفض أو `ABSTAIN`.

## 5. سياسة الرموز والأعداد

يجب أن يكون المصدر UTF-8، وتُطبّق NFC قبل بناء الهوية. تُحفظ قيمة الرمز في AST بصيغة canonical، مع حفظ السطر والعمود للتشخيص فقط. الأرقام العربية والهندية والغربية التي يقبلها lexer تُحوّل إلى تمثيل داخلي مضبوط، ولا يُسمح بالتحويل الضمني بين integer وreal في المسار الحتمي.

## 6. AST canonical

كل عقدة تحمل `النوع`، وتُحفظ حقولها بترتيب ثابت. القوائم المنطقية في AST يجب تحويلها إلى تمثيل غير قابل للتعديل عند اعتماد serializer النهائي. لا تدخل عناوين الذاكرة أو أسماء كائنات Python أو timestamps في المخرج.

## 7. التشخيص والامتناع

| الحالة | القرار |
|---|---|
| رمز غير معروف | `DENY / UNKNOWN_TOKEN` أو `ABSTAIN` حسب Admission Gate |
| نوع غير مدعوم | `ABSTAIN / UNSUPPORTED_TYPE` |
| قوس أو فاصلة منقوصة | `ABSTAIN / SYNTAX_ERROR` |
| real arithmetic دون عقد IEEE-754 | `ABSTAIN / REAL_ARITHMETIC_CONTRACT_MISSING` |
| مصدر أو `source_ref` غير موثق | `ABSTAIN / UNTRUSTED_SOURCE` |

## 8. ما لا تجمّده v0.1

لا تجمّد هذه المواصفة SSA أو IR أو generics أو memory model أو register allocation أو linking أو reproducible binary compiler. تبقى هذه العناصر عقوداً مستقلة من فئة `RESEARCH` حتى تثبت بـcorpus وأدلة منفصلة.

## 9. معيار التجميد

لا تتحول المواصفة إلى `FROZEN` إلا بعد تحقق:

```text
SPEC_JSON_VALID=YES
VALID_CORPUS_PASS=YES
INVALID_CORPUS_REJECTED=YES
BOUNDARY_CASES_CLASSIFIED=YES
AST_REPEATABILITY=PASS
SOURCE_REF_EXECUTED=NO
BASELINE_MODIFIED=NO
SHA256_CHAIN=STATUS=0
```

هذه الوثيقة مواصفة قابلة للمراجعة. وجودها لا يعلن التجميد النهائي قبل اكتمال سجل الأدلة.
