# عقد الساحة المسطحة ذات الفهارس — MAL v0.1

**الحالة:** `RESEARCH / EXTENSION_SCOPED_PROVEN_CANDIDATE`؛ لا يغيّر Grammar v0.1 ولا يرفع MAL-DIR إلى إصدار جديد.

## الغرض

يحدد هذا العقد أصغر تمثيل حتمي يمكن لمدقق MAL-DIR استعماله من غير سجلات runtime أو مؤشرات خام. الساحة هنا قيمة MAL عادية ممثلة بقائمة ثابتة، ويُسمح بالوصول إليها عبر فهرس صحيح غير سالب فقط.

## التمثيل

الساحة المنطقية هي قائمة مرتبة `⟨c₀، c₁، …، cₙ₋₁⟩` ذات طول ثابت معلوم وقت الترجمة. كل خانة قيمة scalar أو نص canonical. لا توجد عناوين أو مؤشرات أو تخصيص يدوي ظاهر في المصدر العربي.

| الحقل | الفهرس | القيد |
|---|---:|---|
| `dir` | 0 | النص الثابت `MAL-DIR` |
| `version` | 1 | النص الثابت `0.1.0` |
| `node_count` | 2 | عدد صحيح موجب |
| `root` | 3 | يساوي `node_count` |
| `source_ref_executed` | 4 | القيمة الصحيحة 0، وتمثل `False` فقط |

## دلالة الفهرسة

التعبير `س[ف]` لا ينفذ عناوين ولا يحولها إلى pointers. يفحص backend أن `0 ≤ ف < طول(س)` ثم يعيد القيمة الموجودة في الخانة. عند فشل الحد يعاد فشل حتمي عبر رمز خروج غير صفري؛ لا تنتج قيمة بديلة.

## سياسة السعة والملكية

الساحة الخاصة بالمدقق ثابتة ولا تنمو أثناء التحقق. لا يسمح للعقد باستعمال `⨁` أو عمليات نسخ/إلحاق لإنشاء ساحة جديدة أثناء المسار الحتمي. لا يسمح بالمؤشرات الخام أو `eval` أو `exec` أو source execution أو الشبكة.

## بوابة القبول

لا تعد هذه الميزة `PROVEN` على مستوى النواة إلا بعد: نجاح تحليل وتجميع المصدر العربي، نجاح تشغيله، تطابق خرجه مع المدقق Python على corpus موجب وسالب، تكرار التشغيل ثلاث مرات بخرج byte-for-byte، ونجاح SHA-256 لسلسلة الأدلة. قبل اكتمال ذلك تبقى الحالة `RESEARCH` و`AUTO_PROMOTION=DENY`.
